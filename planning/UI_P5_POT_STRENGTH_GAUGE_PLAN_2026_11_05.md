# UI準備P-5（計画のみ）：鍋の濃さを「薄い ← 適正 → 濃い」の目盛りにする案

承認してから実装する。表示と配置だけで、判定・評判・乱数・経済（濃さの効き方・水とだしの量・値段）は変えない。

## 今の作り（コードで確かめたこと）

- 鍋タブ（`scenes/ui/kaiten_pot.tscn`・`scripts/ui/kaiten_pot.gd`）の濃さは、数字（`StrengthValue`）と
  **左から塗りつぶす5マスの棒**（`Scale/Cell1..5`、34×14・間隔6）。濃さNなら左からNマスを塗る。1と5は注意色、ほかは強調色。
- 1・5のときだけ注意文「濃さNは評価が1段階下がります」（`StrengthNote`）。
- 濃さの範囲：0〜5（`GameState.STRENGTH_HARD_FLOOR`=0・`STRENGTH_MIN`=1・`STRENGTH_MAX`=5）。
  0＝提供できない（`SaleRule.STRENGTH_ZERO`）、1と5＝1段階下がる（`sale_hint`の`STRENGTH_EXTREME`）、2〜4＝減点なし。
- だし：濃さ+2（5を超えるなら押せない）。水：濃さ−2・残り+2杯（0を下回る・残りが容量−2を超える・今夜の水が無いなら押せない）。
  鍋が空の間は水が先（`pot_locked_until_water`）、濃さ0の間はだしが先（`pot_locked_until_dashi`）。
- ボタンの中の文は固定（だし「濃さ +2」、水「濃さ −2」「+2杯」）。押したあとの値は出ていない。
- 棒の問題：「塗りが多い＝良い」に見える（濃さ5は満タンに見えるが減点）。適正の幅（2〜4）が見えない。

## 画面案（鍋タブの濃さの段。幅388。今の Scale と StrengthNote の位置 y154〜191 に収める）

```
 濃さ                                   3      ← 数字は今のまま（1・5・0は注意色）
 ┌────┬────┬────────────────┬────┐
 │ 出せ│ 薄い│      適正      │ 濃い│      ← 目盛り：0｜1｜2 3 4｜5 の6区画
 │ ない│     │  2   3   4     │  5  │         0＝暗い注意色の斜線、1・5＝薄い注意色、2〜4＝薄い良い色（緑）
 └────┴────┴───────▲────────┴────┘
                     今                    ← 現在位置の印（▲。濃さが変わると動く。1・5・0では注意色）
 薄い ←          適正          → 濃い     ← 目盛りの下の言葉（小さい文字・薄い色）
```

- 目盛りは**6区画**（0〜5）。区画の幅は等しく（388÷6≒64）、区切りの縦線で「適正（2〜4）」を1つの枠に囲う。
- 現在位置は**区画の真ん中に▲**（塗りつぶしをやめる）。濃さ0では「出せない」区画に▲。
- 注意文（`StrengthNote`）は今のまま残す（1・5・0のとき。0は「濃さ0では提供できません」）。

### 操作した後の値を見せる案（だし・水を選ぶ前）

ボタンの中の固定の文を、**今の値→押した後の値**にする（押せるときだけ。押せないときは今のとおりグレーで説明を出さない）。

```
 ┌ だし ─────┐   ┌ 水 ──────┐
 │  だし        │   │  水          │
 │  残り2       │   │  残り1       │
 │  濃さ3→5     │   │  濃さ3→1     │
 │              │   │  残り8→10杯  │
 └──────────┘   └──────────┘
```

- さらに、**ボタンにマウスを乗せている間**は目盛りに「押した後の位置」を薄い▲（点線の輪郭）で出す（`mouse_entered`／`mouse_exited`。表示だけの状態）。
  押した後が1・5なら、その薄い▲を注意色にする（「押すと減点の側に入る」が押す前に分かる）。
- 値は `GameState` の定数（`DASHI_STRENGTH_DELTA`・`WATER_STRENGTH_DELTA`・`WATER_SERVINGS`）から計算し、数を直書きしない。
  計算は `PlaySession.pot_view()` に `after_dashi`（`{strength}`）・`after_water`（`{strength, remaining}`）を足して、そこで作る（UIは読むだけ）。

## 今の警告との関係

| 今ある警告 | 案のあと |
|---|---|
| 鍋タブの数字の注意色（1・5・0） | そのまま |
| 鍋タブの注意文「濃さNは評価が1段階下がります」 | そのまま（0のときの文を足すか＝迷う点2） |
| トッピングの案内文「減点の予告: 濃さ1で1段階下がります。」＋「鍋タブでだし +2」 | そのまま（UI準備Pで文は変えていない） |
| トッピングの鍋タブの「●」（`PotDot`。濃さの手当てが要るとき） | そのまま |
| トッピングの鍋の小表示「鍋 残11杯 / 濃さ3」 | そのまま（迷う点3） |

目盛りは「今どこにいて、押すとどこへ行くか」を見せるもので、警告の条件（いつ注意色にするか）は増やさない・減らさない。

## テスト案（`tests/pot_gauge_test.gd` を新しく足す）

1. 目盛りの区画が6つ・「適正」の枠が2〜4を囲む（位置と幅、4px以内）。
2. 濃さ0〜5のそれぞれで、▲が対応する区画の真ん中にある・色（0・1・5は注意色、2〜4は良い色）。
3. だし：押せるとき「濃さ3→5」、押せないとき（5を超える・だしが無い）は固定の文に戻ってグレー。押したあと、▲が5へ動く。
4. 水：押せるとき「濃さ3→1」「残り8→10杯」、押せないとき（容量・回数・濃さ0を下回る）はグレーで説明を出さない（今の仕様）。
5. マウスを乗せた間だけ薄い▲が出て、外すと消える（`mouse_entered`／`mouse_exited` を送って確かめる）。
6. `pot_view()` の `after_dashi`・`after_water` が `add_dashi`・`add_water` を実際に押した結果と一致する（押した値と予告が食い違わない）。
7. 既存：`ui_kaiten_test`の鍋の寸法（だし・水・鍋の絵）、`pot_adjust_test`・`soup_strength_test` は変えずに通る。v2 の自動試遊は全キー一致（表示だけ）。

## 迷う点（決めてほしいこと）

1. **目盛りの区画を6（0〜5）にするか、5（1〜5）にして0は文だけにするか。** 0は水を足しすぎたときだけで、普段は出ない。6区画だと1区画が狭くなる（64px）。
   案：6区画（0も「出せない」として見える方が、水を押す前の予告で「0になる」を示せる）。
2. **濃さ0の注意文**：今は1・5だけ。0のとき「濃さ0では提供できません。だしを足してください」を足すか（トッピング側の案内文には既に「このままでは提供できません: 濃さ0」が出る）。
3. **トッピングの鍋の小表示**（「鍋 残11杯 / 濃さ3」）も小さな目盛りにするか。案：今回はしない（幅388の1行で、具材を選ぶ画面の主役ではない）。
4. **押した後の値は、ボタンの中の文を置き換えるか、ボタンの外（目盛りの下）に出すか。** 案：ボタンの中（押す物の上に結果がある方が迷わない）。
   ただし水のボタンは86×96で3行が限度。「濃さ3→1」「残り8→10杯」で2行、名前・残り回数と合わせて4行になる → 名前と残り回数を1行（「水 残り1」）にまとめる。
5. **マウスを乗せた予告（薄い▲）**は、タッチ操作（将来のスマホ版）では出ない。ボタンの中の文だけで足りるなら、乗せた予告は入れなくてよい。
6. 「適正」の色を良い色（緑）にすると、札（具＝緑）と同じ色になる。目盛りの地は色を付けず、枠線だけにする案もある。
