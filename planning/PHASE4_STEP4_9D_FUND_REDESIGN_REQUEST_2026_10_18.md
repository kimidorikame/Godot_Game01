## 3. 新しい仕様

### 3.1 修繕の対象（看板・棚・雨よけ・名義）

「累計の境目で段階が上がる」方式をやめ、**修繕の対象ごとに値段を持つ**方式にする。プレイヤーが積む先を選び、値段に達した対象が「修繕済み」になる（途中の対象は進捗を表示）。設定は`week7.json`の`repair_fund.targets`（データ）。

| id | 名前（仮） | 値段（初期値案） | 備考 |
|---|---|---:|---|
| `sign` | 手書きの看板 | 150 | |
| `shelf` | 棚 | 200 | |
| `awning` | 雨よけ | 200 | |
| `owner` | 屋台を自分の名義に | 600 | `DESIGN.md`10.7の最終段階。MVPの7日では届かない。**3つの対象がすべて修繕済みになるまで積めない**（`requires`をデータで持たせる案。重ければ「表示だけして積めない」でよい） |

- 値段・名前・並び順・`requires`はすべてデータ。コードに直書きしない。名前と文面は**仮**（差し替え前提）。
- 帳簿への記帳：`Ledger.record("fund", -額, "repair_fund", 0, 0, 対象id)`。**`ref`に対象idを入れる**。対象ごとの累計＝その`ref`の`fund`の合計。`Result.repair_paid`の合計は`ref`によらず従来どおり。
- `ref`が空の`fund`（4-9①②のテスト・開発中の記帳）は、合計（`repair_paid`）には数えるが、どの対象にも割り当てない（保存の互換のため、読めなくならないこと）。
- 対象への積み立て額は、その対象の残り（値段−累計）を超えない。値段に達したら「修繕済み」で、それ以上積めない。
- 全対象が修繕済みになれば積み立ては完了（ボタンを出さず「完了」）。

### 3.2 1晩の上限

- 1晩に積める額の合計（その日の`fund`の記帳の合計）に上限を設ける。データ`repair_fund.nightly_max`、**初期値30**。
- 積む額の刻み（`steps`）は**10と30**（初期値案）。1晩30を1回、または10を最大3回。
- **最終日にも同じ上限が掛かる**（最終日の一括払いを防ぐ）。
- 初期値の意味：7夜すべてに30を積んで最大210。看板（150）は5夜、棚か雨よけ（200）は7夜すべてで届く。**3つ同時にはどうやっても届かない**（MVPの目標「どれか1つが修繕できる」）。

### 3.3 安全上限（見直し）

積めるのは、次の**すべて**を満たす額まで：
- 対象の残り以内
- 今夜の1晩の上限の残り以内
- **安全上限（新）**以内

安全上限（新）＝`使える現金（Ledger.usable_cash()）− 翌日の確保額`（0未満は0）。**翌日の確保額**は次の合計：
1. 翌朝に必ず払う運営費（`GameState.DAILY_OPERATING_COST`）
2. 翌日が徴収日なら請求の合計（`Rules.bills_total_on(day_count+1)`）
3. **翌日の仕込み**：見込み杯数に足りる最小の段階の価格（`Rules.prep_tiers()`）
4. **翌日の材料費**：見込み杯数 × 1杯あたりの材料費の目安（**味1＋具2＝3つ分**の素材の代表単価）

- **今日が最終日なら**翌日が無いので、確保額は0（上限は使える現金そのもの。1晩の上限は掛かる）。
- 見込み杯数：翌日の需要の見込み。**推奨は、現在の評判で引く総需要（`Rules.demand_table()`）と、今日の計画杯数の大きいほう**。閉店後に評判が動くため多少ずれる。
- 材料費の目安（1杯）：**推奨は市場の品目データから計算する**（味の素材・具の素材の1個あたりの価格＝`price/count`の中央値を求め、味1個＋具2個として合算）。固定値を置かないので、価格を変えても追従する。計算が重い・曖昧なら、`week7.json`に定数（`cup_material_cost`。③の測定から約19が目安）を置く代案でよい（planで判断）。
- 画面には、上限の近くに「明日の仕入れ分を残す」旨を出す（仮文面）。

### 3.4 試算（基準方針の実測値から。実装後の再実行で確かめる）

材料費の目安を1杯19とし、見込み杯数をDay2=9・Day3=11・Day4以降=14と置いた**机上の試算**：

| 夜 | 基準の夜の現金 | 翌日の確保額 | 安全上限による累計の上限 |
|---|---:|---:|---:|
| Day1 | 510 | 約346 | 約164 |
| Day2 | 617 | 約384 | 約233 |
| Day3 | 812 | 約471 | 約341 |
| Day4以降 | 979〜 | 約471 | 約508〜 |

→ 1晩30の上限が先に効くので、安全上限は現金が苦しい周でだけ働く見込み（毎晩30を積んでも最大210で、基準方針の現金には影響しないはず）。

## 6. テスト・自動試遊
