# 『夜湯』6日目　昼市場（張姐・海叔・ヨヨ・梁伯）

## この稿について

- **表記の決まり**：`〔ゲーム〕` の行はゲームの処理（表示しない）。「名前「セリフ」」だけを会話枠に出す。ト書きは書かない。
- **流れ**：市場に着く → 張姐（必須）→ 仕込む量を選んで出汁を買う → 買い物（海叔・ヨヨは寄った人だけ）→ 市場を出るときに梁伯（必須）。
- 火事は今夜（午前2時ごろ）。昼の市場では、まだ何も起きていない。火事を予告する文は入れない。
- 昼に聞いた「受け取る口」「冷やす」「置く場所」が、火事のあとの連絡で、そのまま心配事に変わる。
- **話し方**
  - 張姐：早口でたたみかける。最後は質問で締める。店主を「アンタ」と呼ぶ。
  - 梁伯：命令と説教。同じことを二度言う。「〜しな」「〜とる」。答えを急がない。
  - 海叔：愛想がいい。「〜だよ」「〜ね」。娘の話が混ざる。
  - ヨヨ：よくしゃべる。売り込みが上手いが、使い切れるかを真面目に聞く。「〜でしょ」「〜の」。
  - 店主：短く受ける。
- **この場面で伝えること**
  - 張姐：明日の骨の便は「受け取る口を確認中」。今日の分は今日ある（必ず通る）。
  - 梁伯：答えを一つに急ぐな（必ず通る。火事のあとに効く）。

## 張記肉類加工　張姐　※市場に着いたとき

張姐「今日は、そこへ袋を置いていいよ。空箱は出せたから」  
店主「ようやく箱屋をやめたか」  
張姐「朝のうちだけね。空いた所へ次の荷を置くから、今が一番よく見える」  
店主「床、こんな色だったか」  
張姐「洗ったからね。昨日、箱をどけたら、うちの輪ゴムが山ほど出てきた」  
店主「拾って使うのか」  
張姐「袋へ戻すわけないでしょ。あれだけ落としてたんだって、自分に腹が立ったの」  
店主「昨日の骨、よく出たぞ」  
張姐「ならよかった。今日のも冷やしてある。そこ、口を広げて」  
店主「明日の便は」  
張姐「受け取る口を確認してる。いつもの運転手が、今度はどこへ着ければいいかって」  
店主「ここで下ろすんじゃないのか」  
張姐「最後はここよ。その前の積み替えがまだ決まらない。荷を受ける所が、また変わるかもしれないってさ」  
張姐「六日よ、六日。六日たって、まだ『確認中』。うちの骨は冷やして待てるけど、電気の勘定は待ってくれないのよ？」  
店主「今日、多めにもらっとくか」  
張姐「明日までどこで冷やすの。あんたの置き場が先でしょ」  
店主「今夜の分で、だいたい埋まるな」  
張姐「じゃ、今夜の分。心配だからって、置けない骨を抱えて帰らない」  
店主「明日はどうする」  
張姐「分かったら連絡する。着く時刻も含めてね。今、言えるのは今日の骨があること」  
店主「それは助かる」  
張姐「そこはきっちりやるよ。……袋、曲がってる。片方だけ引っ張らない。で、今日はどれ位仕込む？」  

〔ゲーム〕仕込む量を選び、出汁を購入。

張姐「受け取ったら、冷やす方を先にね。買い物しながら袋を振り回さないの」  
店主「子どもじゃないぞ」  
張姐「骨もおもちゃじゃないよ」  

## 海隆鮮貨　海叔　※寄った人だけ（店ごとの会話の仕組みができたら）

海叔「いらっしゃい。今日は箱の影、こっちにしてね。昼の光が動いたから」  
店主「魚は来たか」  
海叔「今日のはね。ほら、この記録。冷えて着いてる。顔も見た。今夜使うなら、この辺だよ」  
店主「明日の便もそこに出るのか」  
海叔「そこまで見えたら、娘が先に使うよ。いつ休みになるのか、毎回聞かれるから」  
店主「返事はしたか」  
海叔「『今週のどこか』って送ったら、『もう半分過ぎた』って」  
店主「過ぎたな」  
海叔「うん。だから今度は、先に日を決めようと思ってる」  
店主「店を閉めるか」  
海叔「時間を少し。家の飯まで、売り切れてからじゃ遅いからね」  
店主「娘が作ってくれるのか」  
海叔「一緒に作る約束。買い物からだって」  
店主「魚ならここにある」  
海叔「そう言ったら、今日は魚屋さんじゃなくて、お父さんで来てって」  
店主「何を買うんだ」  
海叔「まだ教えてくれない。持つ袋だけは用意しとけってさ」  
店主「運ぶ係は同じか」  
海叔「隣を歩けるなら、それでいいよ」  
店主「明日の入荷は」  
海叔「まだ返事待ち。氷も箱も、今夜使う分はある。ただ、受け取る場所が変わるなら、そっちにも箱を用意しないと」  
店主「車に載せっぱなしじゃ駄目か」  
海叔「冷やせる間はいい。でも何時まで待つのか分からないと、売る約束はしづらいよ」  
店主「今日は見て買えるな」  
海叔「そう。今日はここで見て。あんたが夜まで持たせられる分だけね」  


## 半端市「拾味」　ヨヨ　※寄った人だけ（店ごとの会話の仕組みができたら）

ヨヨ「見て、この箱。上から撮ったら、靴箱くらいにしか見えないの。横からのも載せたよ」  
店主「ずいぶん空箱が写ってるな」  
ヨヨ「中に何を入れるか決まってない人が多いの。先に箱だけって」  
店主「置いとく場所はあるのか」  
ヨヨ「そこ。聞くと黙る。安くても、床は増えないからね」  
店主「お前の床も埋まってるぞ」  
ヨヨ「それは行き先が決まってる方。こっちの札、名前があるでしょ」  
店主「いつ取りに来る」  
ヨヨ「……時刻は、まだ」  
店主「似たようなもんじゃないか」  
ヨヨ「分かってる。だから連絡してるの。『取りに来る』の次を教えてって」  
ヨヨ「返事が『大きさは大丈夫』なの。入るかどうかは、もう一緒に測ったでしょって」  
店主「箱のことしか返ってこないか」  
ヨヨ「そう。来る人の方の予定が欲しいのに」  
店主「売る前の写真が良すぎたな」  
ヨヨ「そこは褒めていいよ。今度は持った写真も足す。ひとりで運ぶと、両手がふさがりますって」  
店主「お前が持つのか」  
ヨヨ「誰かに撮ってもらう。私が持って、私が撮ると、また箱の内側しか写らない」  
店主「俺の買い物も、聞かれるか」  
ヨヨ「何を買うかによる。鍋に入る物なら、今夜どれだけ使うか」  
店主「全部って言ったら」  
ヨヨ「嬉しいけど、もう一回聞く。明日使えなくなったのを、うちのせいにされたくないし」  
店主「商売熱心だな」  
ヨヨ「また買いに来てもらう方のね。……その袋、今日の鍋で使い切る？」  


## 共同水場　梁伯　※市場を出るとき

梁伯「こっちだ。水缶はこっち。ホースの上を越えようとするな」  
店主「今日はホースが長いな」  
梁伯「洗い場の置き場を動かした。荷を避けたら、蛇口から遠くなった」  
店主「毎日、物が引っ越すな」  
梁伯「水だけは、坂の上へ勝手に引っ越してくれんからな。こっちで持っていく」  
店主「昨夜、警官に道を教わった。角を一つ先だと」  
梁伯「荷車のことを聞かれたよ。人が歩く分には狭く見えんのだろうな」  
店主「今日は通れた」  
梁伯「足の速い子だな。こっちが荷を載せる前に先へ行こうとするから、まだだと言った」  
店主「待ったか」  
梁伯「待ったよ。空の荷車で道を覚えられても困る」  
店主「次は、重い方を覚えたな」  
梁伯「それを、明日も覚えとってくれりゃいい」  
梁伯「帰りも見るんだよ。今度は骨と水が載っとる」  
店主「分かってる。そっちも旧倉庫まで行くのか」  
梁伯「今日はここを空けられん。あっちを見た者から、使い終わった口は閉まっとったと聞いた。自分で見るのは次だ」  
店主「それでも数字は動くか」  
梁伯「使う間は動く。使わん間にどうかは、また確かめる。慌てて答えを一つにするな」  
店主「俺は、水が汲めりゃいいんだがな」  
梁伯「だから見とるんだよ。ほら、へこみまで。止めな、止めな」  
店主「閉めた。蓋もな」  
梁伯「今日は水缶を下ろす場所も見てから帰りな。道の真ん中で休むなよ」  

〔ゲーム〕払うのは、いつもの日の分だけ。


## 実装メモ

| 項目 | 内容 |
|---|---|
| 張姐 | 6日目の市場の場面。「で、今日はどれ位仕込む？」は仕込む量を選ぶ場面の文。選んだあとに3行ある。 |
| 梁伯 | 市場を出るときの場面。払い方と額は変えない。計器に火事の前触れは出さない。 |
| 海叔・ヨヨ | 店ごとの会話の仕組みはまだ無い。必ず伝える情報は入れていない。 |
| 状況が悪くなっている感じ | 張姐「六日たって、まだ『確認中』」。明日の便の受け取り口が決まらない。海叔も「返事待ち」。ヨヨの売り場は、行き先だけ決まって取りに来ない箱で埋まっている。 |
| 火事のあとに効く所 | 張姐「置けない骨を抱えて帰らない」→ 夜中の「明日の支度を増やさず待ってて」。海叔「何時まで待つのか分からないと、売る約束はしづらい」→ 夜中の「受け取る場所が決まってない」。梁伯「慌てて答えを一つにするな」→ 放火か事故かで揺れる夜。 |
| 暮らしの部分 | 海叔の娘との休みの約束（「今週のどこか」「もう半分過ぎた」）、ヨヨの「床は増えないからね」。 |
| 今回の加筆 | 空箱をどけたあとの床、海叔と娘の買い物、ヨヨの箱の写真、梁伯が見たリンの学び方。「冷やす機械は待たない」は、待機中も冷却の費用がかかる話として言い換えた。新しい料金や在庫の処理は足さない。 |
| たたき台から足した所 | 張姐の「六日よ、六日」の1行。 |
