# 『夜湯』6日目・明け方　レックス（チンピラ）火事のあと

## この稿について

- **表記の決まり**：`〔ゲーム〕` の行はゲームの処理（表示しない）。「名前「セリフ」」だけを会話枠に出す。ト書きは書かない。
- **話し方**
  - レックス：短文で乱暴。「〜ねえ」「〜だろうが」、命令形。金と帳面の話だけ、急にきっちりする。一人称は「俺」。今夜は酔っているが、勘定と腕の手入れは普段どおり。
  - 店主：短く受ける。**投稿の話はしない。**
- 午前4時すぎ。兄貴分と飲んでいた帰り。火事のあと、通りを止められながら歩いて来た。
- **この場面の前に、店主はニカの投稿（兄貴分が焼かせた、と言い切った投稿）を読んでいる。** レックスはまだ読んでいない。
- 1杯。注文は まろやか＋やさしい（いつもの注文）。好物は肉団子。
- レックスは、自分が知っていることだけを話す。サイレンのとき、兄貴分と同じ店にいた。兄貴分は新しい窓口から、日雇いの人集めを請けた。

## 本編

### 来店・注文

レックス「……やってんな」  
店主「今ある分はな。前には立つな。通りを空けてる」  
レックス「見りゃ分かる。椅子、内側か」  
店主「ああ。その席」  
レックス「歩いて来たら、最後の角で止められた。戻って、また曲がって。飲んだ店の方が近くなりやがった」  
店主「まだ飲んでたのか」  
レックス「今、出たとこだ。もういらねえ」  
店主「椅子、もう少しこっちへ」  
レックス「これ以上寄せたら、腹が台に当たる」  
店主「腕の分だ。そこじゃ通る人に当たる」  
レックス「……ああ。肘、こっちに入れとく」  
店主「そのままで食えるか」  
レックス「食える。椀を遠くへ置くなよ」  
店主「白い汁か」  
レックス「それ。まろやかで、具もやさしいやつ。……丸いのも、あったら入れろ」  
店主「肉団子だな」  
レックス「分かってんなら聞くな」  
店主「一応な」  
レックス「今日は俺の返事まで取り直すな。通りで何回も、どっから来たって聞かれた」  

### 提供と反応

〔ゲーム〕1杯。まろやか＋やさしい（いつもの注文）。好物は肉団子。判定の結果で、次のうち1つだけ出す。

- **GREAT**　レックス「……丸いの、いるな。白い汁に、やわらけえ具。これでいい。俺の皿からは、誰も取らねえしな」
- **GOOD**　レックス「白くて、やわらけえ。ああ、今はこれでいい。ゆっくり食う」
- **OK（まろやかは合った）**　レックス「汁はいい。具もやさしい方って言ったろうが」
- **OK（やさしいは合った）**　レックス「具はこれだ。白い、まろやかな汁で食いたかったんだよ」
- **BAD**　レックス「……白くてやさしいの、って言ったぞ。俺、そんなに呂律回ってなかったか」

### 食事・サイレン

店主「サイレンは聞いたか」  
レックス「あの店で聞いたよ。最初、店の外で鳴ってんのかと思った」  
レックス「店の奴が画面を港の速報に替えた。兄貴もいたよ。サイレンが鳴ったとき、俺の隣に」  

店主「そうか」  
レックス「そうだよ。俺、隣にいた」  

店主「兄貴分は、どうしてた」  
レックス「……端末が鳴るたびに、席を立ってた。戻ってくると、酒が減ってねえんだ」  
店主「何の話だ」  
レックス「聞くかよ。聞いて、答えが返ってきたら、どうすんだ」  


### 食事・新しい窓口の仕事

店主「兄貴分、最近は港によく呼ばれてたんだろ」  
レックス「ああ。新しい窓口の仕事だ。人を集める方を、うちで請けるって」  
店主「荷を運ぶ人間か」  
レックス「日雇い。どこで何人要るだの、いつ集めるだの。俺が聞いたのはそこまでだ」  
店主「お前も行くのか」  
レックス「俺には、まだ何も来てねえ」  
店主「今夜、聞いたか」  
レックス「飲んでるときにな。仕事を取りに行ったって。それまでは、呼ばれてることしか知らなかった」  
店主「お前は人数の勘定もするのか」  
レックス「頼まれてねえ。俺が触ってねえ帳面まで、合ってるなんて言えるかよ」  
店主「金の方は細かいな」  
レックス「そこを雑にしたら、俺が取りに行く時も雑でいいって話になる」  
店主「その仕事場が止まったら、どうなる」  
レックス「……知らねえ。誰に聞いても、まだ決まってねえ話ばっかりだ」  
店主「うちも朝の骨が決まらん」  
レックス「骨までか」  
店主「物がなくなったかも分からん。車をどこへ通すか、返事待ちだ」  
レックス「腹は、返事待ってくれねえぞ」  
店主「お前が座ってるから分かる」  
レックス「そっちは、誰の返事を待ってんだ」  
店主「肉屋だ。向こうは運転手の返事待ち」  
レックス「その先も、誰か待ってんだろうな」  
店主「今日の分は、待たせてないぞ」  
レックス「食ってるだろ。……熱い」  

### 食事・腕と上着

レックス「布、あるか。水が跳ねた」  
店主「腕か」  
レックス「継ぎ目。下の道、濡れてた。酔ってても、ここは拭いとく」  
店主「上着の方も濡れてる」  
レックス「吊るしゃ乾く。こっちは、朝になったら直ってるわけじゃねえ」  
店主「布の乾いた方を使え」  
レックス「……ああ」  
レックス「この端、まだ乾いてるな」  
店主「折って使え」  
レックス「いつもそうしてる。汚れた面を、もう一回ここへ当てんなって言われた」  
店主「修理屋にか」  
レックス「一度で覚えたよ。覚えたから、酒が入っててもやってんだ」  
店主「なら、椀は置いてやれ」  

店主「また端末が鳴ってるぞ」  
レックス「帰りに読む。今は、飯と腕で手がふさがってる」  
店主「それも仕事の話か」  
レックス「開いてねえから、分かるかよ」  


### 会計・退店

〔ゲーム〕会計（1杯分）。場所代は取らない。

レックス「これで足りるな」  
店主「足りる。こんなときでも勘定は間違えんな」  
レックス「俺が食った分だろ。間違えるほど頼んでねえ」  
店主「布、そこへ置いとけ」  
レックス「その箱も、内へ入れんのか」  
店主「空の方だけな」  
レックス「……こっちだな」  


店主「帰れる方、見てから行けよ」  
レックス「分かってる。看板の矢印より、人が立ってる所を聞く」  
店主「明日は、通れる所がまた変わるかもしれん」  
レックス「……ああ。明日のことは、明日聞く」  

## 実装メモ

| 項目 | 内容 |
|---|---|
| 注文 | まろやか＋やさしい（データのまま。2日目だけ今日の頼みだった）。好物は肉団子。 |
| レックスが言うこと | サイレンは飲んでいた店で聞いた。兄貴分もそこにいた（「俺の隣に」）。兄貴分は新しい窓口から、日雇いの人集めを請けた。自分には何も来ていない。 |
| レックスの疑い（口に出し切らない） | 「端末が鳴るたびに、席を立ってた。戻ってくると、酒が減ってねえんだ」「聞いて、答えが返ってきたら、どうすんだ」。兄貴が何か知っているかもしれない、と思っている。知りたくない。かばうようにも、自分に言い聞かせるようにも聞こえる。 |
| プレイヤーにどう聞こえるか | 投稿を読んだあとなので、「兄貴もいた」は言い訳にも聞こえる。レックス本人は投稿を知らないので、反論はしない。店主も言わない。 |
| 確かなこと・確かでないこと | 店主が自分の目で見たのは、明け方にこの男が一人で来たことだけ。サイレンのとき一緒にいたのは本当（書き手用）。ただし、それで出火の時刻や、指示が無かったことまでは決まらない。 |
| 大変な事になった感じ | 通りで何回も「どっから来た」と聞かれた。誰に聞いても「まだ決まってねえ話ばっかり」。店主「うちも朝の骨が決まらん」。 |
| 暮らしの部分 | 酔っていても継ぎ目を拭く。勘定は間違えない。空の箱を内側へ寄せる。「腹は、返事待ってくれねえぞ」。 |
| つながり | 番号の客・知らない顔＝兄貴分の組が集めた日雇い（4・5日目）。継ぎ目を拭く＝1日目。「明日のことは、明日聞く」＝1日目の阿強「明日の俺は、明日の俺が面倒見る」と対。 |
| 鳴っている端末 | 中身は見せない。ニカの投稿が届いたのかどうかは決めない。 |
| たたき台から足した所 | 「兄貴分は、どうしてた」の4行（レックスの疑い）。 |
| 今回の加筆 | 義腕の分だけ座り直す、触っていない帳面には答えない、連絡を待つ相手をたどる、酔っても布を折り返す手入れ。兄貴分といた時刻を増やしたり、出火への関与を確定させたりはしない。投稿は最後まで未読。 |
