# 『夜湯』2日目　朝のDM（レックス）

## この稿について

- スマホの「SNS」タブのDMに、2日目の朝に届くショートメール。差出人は名前で出る（DMは知っている相手との連絡）。
- 遊びに効くことは本当のことだけ書く。レックスは今夜（夜半）に来て、好物は肉団子。買い物の前に読めるので、肉団子を仕入れる手がかりになる。
- 数字と「客足」は入れない。金額も書かない。

## 本文（2通が続けて届く形。1通にまとめてもよい）

| 差出人 | 時刻 | 本文 |
|---|---|---|
| レックス | 4:40 | 昨日あのあと兄貴に呼ばれた。焼肉だ。俺の皿に乗ったのは玉ねぎ一枚。 |
| レックス | 4:42 | 今夜は客で行く。帳面は持ってかねえ。丸いの、取っとけ。 |

## 1通にまとめる場合

| 差出人 | 時刻 | 本文 |
|---|---|---|
| レックス | 4:40 | 昨日あのあと兄貴に呼ばれた。焼肉なのに肉が食えなかった。今夜は客で行く。帳面は持ってかねえ。丸いの、取っとけ。 |

## 実装メモ

| 項目 | 内容 |
|---|---|
| 置き場所 | data/dm/week7.json の2日目。条件は「レックスに会っている」（requires customer: thug）。1日目に必ず会うので、必ず届く。 |
| 来店予告との関係 | 2日目の朝は、今の仕組みだと来店予告（previews の thug の文）も出る。同じ人から似た文が2つ並ばないよう、2日目のレックスは、予告の文の代わりにこの文を出す。 |
| 本当のこと | 今夜来る（2日目・夜半）。場所代は取らない（1日目に払い済み）。「丸いの」＝肉団子（好物）。1日目の退店時の「いつもは肉だろ」ともつながる。 |
| 台本とのつながり | 夜の「昨日、ここを出たあとで呼ばれた。焼肉だ」「注いで顔を上げたら、網の上が空」と同じ話。タイムラインの「継ぎ目」（レックスの表アカ）17:10 の投稿とも同じ話。 |
| 外す文 | 今の仮のDM d2_delivery_man（阿強「また夜に寄るよ」）は、阿強が2日目に来ないので外す。差し替えの案：阿強 5:50「昨日の容器、門のおっさんに預けてきた。返ってきたら持ってく」（3日目に容器を届ける話につながる。来る日は言っていない）。 |
| 外す文 | 今の仮のDM d2_market（市場の顔なじみ「入荷が遅れてる。早めに来な」）は、差出人を張姐にして残してよい。案：張姐 6:40「豚骨、今日は着くのが遅れる。検問だってさ。来る時間は変えなくていいよ」。 |
| 2日目の来店予告で気をつける所 | 今の仕組みでは、2日目の朝に新人警官の予告（「今夜、巡回のあとに寄る予定です」）も出うる。まだ会っていない相手（市場で初めて会う）からDMが来るのはおかしいので、会う前の客の予告は出さない。セティヤの予告は、差出人を「セティヤ」にして出してよい（元々の常連）。文の案：「今夜、仕事が早く済んだら寄るわ」は今のままで台本（早上がり）と合う。 |
