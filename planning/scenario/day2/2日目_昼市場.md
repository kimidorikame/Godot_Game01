# 『夜湯』2日目　昼市場（張姐・新人警官との出会い）

## この稿について

- **表記の決まり**
  - `〔ゲーム〕` で始まる行は、ゲームの処理。画面に文字としては出さない。
  - それ以外の「名前「セリフ」」だけを会話枠に出す。絵や動きの指示（ト書き）は書かない。人物は胸から上しか映らない前提で、必要なことはセリフで分かるようにしてある。
- **流れ**：市場に着く → 張記で張姐と話す → 仕込む量を選んで出汁を買う → **張記を出たところで新人警官に声をかけられる** → 市場で買い物 → 市場を出る。
- **話し方**
  - 張姐：早口でたたみかける。最後は質問で締める。店主を「アンタ」と呼ぶ。
  - 警官（リン）：丁寧で生真面目。「〜です」「〜ました」。一人称は「私」。まだ名前は出ない（表示名は「警官」）。
  - 店主：短く受ける。「〜か」「〜な」。
- **2日目に伝えること（この場面の分）**
  - 張姐：港の手前で検問が始まった。置き場に困った荷を、奥の旧倉庫へ回している（必ず伝える）。
  - 警官：今夜の注文は「酸っぱい汁」と「噛めるもの」。買い物の前に分かる。
- 2日目は雨ではない（雨は3日目だけ）。

## 張記肉類加工　張姐　※市場に着いたとき

張姐「来たね。豚骨、今日は着くのが遅れたよ。で、昨日の骨はどうだった？」  
店主「だしはよく出た。遅れたって、車か」  
張姐「検問。港の手前で、一台ずつ荷札を読んでるんだって。うちの運転手、骨の箱を三回数え直されたってさ。骨だよ？」  
店主「骨の数まで見るのか」  
張姐「箱の数。機械が読んで、人がもう一回読んで、それが合わないともう一回」  
張姐「それでね。八番の置き場に困った荷は、奥の旧倉庫へ回してるってさ。あそこ、何年も閉めてたでしょ？」  
店主「灯りも点いてなかったな」  
張姐「それが昨夜は点いてたって。で、今日はどれ位仕込む？」  

〔ゲーム〕仕込む量（鍋の大きさ）を選んで、出汁を買う。

## 張記を出たところ　新人警官　※買い物の前

警官「すみません。この市場の方ですか」  
店主「夜だけな。昼は買う側だ」  
警官「搬入口を探しています。地図では、この先を右なんですが」  
店主「右は正面口だ。あんたの言う搬入口は、どの搬入口だ」  
警官「……いくつもあるんですか」  
店主「三つ。標識が付いてるのは一つだけだ」  
警官「先輩に『搬入口で待て』と言われて、標識のところで待っていました。二十分」  
店主「来なかったろ」  
警官「来ませんでした。視界の経路表示も、何度引き直しても正面口に戻されます」  
店主「配達の連中も同じことを言ってる。その地図、ずっと昼なんだ」  

店主「制服の連中が集まるのは、倉庫通りに面した裏の口だ。表札はない」  
警官「表札のない方……」  
店主「魚屋の裏を抜けて、氷の溶けた水が流れてる方へ行け」  
警官「氷の水は、地図に書けませんね」  
店主「靴が濡れたら合ってる」  

警官「分かりました。……あの、夜はそこで何かを？」  
店主「屋台だ。日が落ちたら、その裏の口でスープを出してる」  
警官「今日が勤務の初日で、朝から立ち通しなんです。夜の休憩で、寄ってもいいですか」  
店主「客なら歓迎だ。何が食いたい」  
警官「酸っぱい汁が好きです。それと、ちゃんと噛めるもの。訓練所の食事は、時間が無くて噛む前に飲み込んでたから」  
店主「酸っぱくて、歯ごたえのあるやつだな。仕入れとく」  
警官「いいんですか」  
店主「来なかったら、俺が食う」  
警官「行きます。迷わなければ」  
店主「鍋の匂いがする方だ。それも地図には書けないけどな」  

警官「ありがとうございました。……あ、先輩から通信です。『どこの搬入口にいる』と」  
店主「表札のない方だと言っとけ」  

〔ゲーム〕市場で買い物（ここから店を選べる）。

## 寄った店のひとこと（寄った人だけ・仕組みができたら）

海叔「明日は一日雨だよ。貝を買うなら、今日のうちに使いな。明日は客足も読めないからね」  

## 実装メモ

| 項目 | 内容 |
|---|---|
| 張姐の会話 | 2日目の市場に着いたときの場面。今は1日目にしか市場の場面（day1_market）が無いので、2日目の分を足す必要がある。 |
| 警官の会話 | 今ある仕組み（officer_01 の market_talk。出汁を受け取ったあと・買い物の前）にそのまま入る。 |
| 注文の手がかり | 「酸っぱい汁」＝酸っぱい（塩漬けライム）。「ちゃんと噛めるもの」＝歯ごたえ（軟骨・乾燥きくらげ・すじ肉）。どれも2日目の市場で買える。 |
| 必ず伝える情報 | 張姐：検問の開始、旧倉庫への荷の回し。 |
| つながり | 「その地図、ずっと昼なんだ」＝1日目の阿強。「来なかったら、俺が食う」＝阿強の三杯目。「表札のない方」「靴が濡れたら」「鍋の匂い」は夜の来店で返す。リンの裏アカの「勤務は明日から」（1日目 23:50）とも合う。 |
| 海叔のひとこと | 店ごとの会話の仕組みはまだ無い。雨の予告はセティヤの会話にも入れてあるので、無くても伝わる。 |
