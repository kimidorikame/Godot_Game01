# 『夜湯』2日目・夜半　レックス（チンピラ）

## この稿について

- **表記の決まり**
  - `〔ゲーム〕` で始まる行は、ゲームの処理。画面に文字としては出さない。
  - それ以外の「名前「セリフ」」だけを会話枠に出す。ト書きは書かない。
- **話し方**
  - レックス：短文で乱暴。「〜ねえ」「〜だろうが」、命令形。金と帳面の話だけ、急にきっちりする。一人称は「俺」。
  - 店主：短く受ける。「〜か」「〜な」。
- 2回目の来店。今夜は場所代ではなく、自分の飯を食いに来る。兄貴分の話は、二人の普段の付き合いから入る。
- 金額はセリフで言わない。2日目は雨ではない。

## 本編

### 来店

店主「レックス、今日は帳面なしか」  
レックス「場所代は昨日もらったろうが。今日は客だ」  
店主「腹、空かせて来たか」  
レックス「空いてる。空いてるが、胃はまだ駄目だ」  
店主「また兄貴分か」  
レックス「昨日、ここを出たあとで呼ばれた。焼肉だ」  
店主「いいもん食ったじゃないか」  
レックス「食ってねえ。俺は酒を注ぐ係だ。注いで顔を上げたら、網の上が空になってる」  
店主「兄貴分は食うのが早いのか」  
レックス「早いんじゃねえ。兄貴の新しい指は熱を感じねえんだ。網から直に取りやがる」  
店主「お前の腕でやればいいだろ」  
レックス「俺のは殴り合い用だ。掴めるが、掴んだ肉が潰れる」  

### 注文

レックス「だから今日は肉をくれ。丸いやつ、肉団子でいい」  
店主「汁は」  
レックス「汁は昨日の白いのだ。具は肉だ肉。先に胃へ貼っとく」  
店主「肉の上に肉か」  
レックス「そう肉だ。昨日の分も食うんだよ」  

### 提供と反応

〔ゲーム〕1杯。注文は まろやか＋スタミナ。好物は肉団子。

〔ゲーム〕判定の結果で、次のうち1つだけ出す。

- **GREAT**　レックス「……あるじゃねえか、丸いの。誰にも取られねえ肉は、うめえな」
- **GOOD**　レックス「……胃が生き返る。肉はいいよな。次は入れろよ」
- **OK**　レックス「悪くねえ。が、白いのに肉、って言ったんだけどな」
- **BAD**　レックス「……てめえも、俺の肉を取る側かよ」

### 食事・検問と義腕

レックス「今日は通りを回ったんだがよ。検問で三回止められた」  
店主「組の上着のせいか」  
レックス「腕だ。読み取り機が俺の腕を見て『荷役機器・持ち出し確認』って出しやがる」  
店主「持ち出されたのか」  
レックス「俺の腕だ。買ったのも俺、改造したのも付いてんのも俺だ」  
店主「で、どうした」  
レックス「修理屋の領収書を見せた。部品代と工賃、別々に書かせといて正解だったぜ」  
店主「それで通るのか」  
レックス「新米らしい警官が、三回読んで、三回謝った。真面目な奴だ」  

店主「兄貴分も止められたのか」  
レックス「兄貴は止められねえ。新しい型は、機械が読んでも人間のままだ」  
店主「同じ上着でもか」  
レックス「上着は同じだ。中身の値段が違う」  
店主「年に何度か、お前と帳面を見に来る人だろ」  
レックス「ああ。最近は港の方によく呼ばれてる。何の用かは聞くな。俺も聞いてねえ」  

### 食事・看板

レックス「看板はどうした。夜湯」  
店主「金を貯めてるところだ」  
レックス「字を書くのに金が要るのかよ」  
店主「板が要る」  
レックス「……板か。板は要るな」  

### 会計・退店

〔ゲーム〕会計（判定とチップで決まる額。セリフでは言わない）。

レックス「ごちそうさん。今日は帳面なしだ。スープ代だけ払う」  
店主「話が早いな」  
レックス「揉めるのは月に一度でいい」  
店主「次はいつ来る」  
レックス「兄貴に呼ばれなきゃ来る。呼ばれたら、また肉抜きだ」  
店主「そのときは、ここで食い直せ」  
レックス「そのつもりだ。丸いの、取っとけよ」  

## 実装メモ

| 項目 | 内容 |
|---|---|
| 来店 | レックス一人。1杯。場所代の支払いは無い（1日目に払い済み）。 |
| 注文 | まろやか＋スタミナ。手がかり：「汁は昨日の白いの」「肉」。 |
| 好物 | 肉団子。手がかり：「丸いやつ、肉団子でいい」（改訂版の好物のヒント）。GREAT は、白い汁＋スタミナの具＋肉団子の3つで取れる。 |
| 2日目に伝えること | 検問が街の通りにも及んでいる。兄貴分の紹介（組の揃いの上着、新しい改造、年に何度か帳面を見に来る、最近は港の方に呼ばれている）。 |
| 前振り | 「最近は港の方によく呼ばれてる」＝5日目のニカの映像、6日目の「兄貴もいた」。「買ったのも俺、付いてんのも俺」「部品代と工賃は別々」＝1日目。看板は修繕基金の「手書きの看板」（2日目までに買える額にはならないので、「貯めてるところ」は必ず本当）。 |
| 気をつけた点 | 「新米らしい警官」はリンと決めていない（リンの持ち場は市場の出入口）。プレイヤーが想像できる程度にとどめた。次の来店は6日目なので、「すぐ来る」とは言わせていない。 |
| あとで足すもの | 具だくさん（具2種類）の一言、断ったときの一言。 |
