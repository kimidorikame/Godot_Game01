# 『夜湯』3日目　モブ3組（安宿の夜勤受付・雑貨屋の夜番・夜間清掃員）

## この稿について

- **表記の決まり**：`〔ゲーム〕` の行はゲームの処理（表示しない）。「名前「セリフ」」だけを会話枠に出す。ト書きは書かない。
- **杯数**：何杯になるかはゲームが決める（1組1〜4杯）。本文は1杯の晩にも読める。「2杯以上のときだけ」の1行は、中身Xの形（min_count）で出す。杯数ごとに文を変えない。
- 一組は一つの椀・判定は1回。モブなので GREAT は無い。OK は、どちらの札が外れたかで2通り。
- **来る順**：組が1つの晩は夜半（雑貨屋の夜番）だけ。2つなら宵の口（受付）も。3つなら明け方（清掃員）も。必ず伝える情報はモブに置いていない。
- **話し方**
  - 受付：客商売の丁寧語。段取りを一息で説明する。「〜なんです」「〜でして」。
  - 雑貨屋の夜番：ぼやき屋。売れ残りを年数で覚えている。「〜でな」「〜だよ、まったく」。
  - 夜間清掃員：言葉が少ない。仕事の理屈で話す。「〜だ」「〜な」。
- 一日中雨。金額はセリフで言わない。

## 宵の口　安宿の夜勤受付（阿強のあと）

受付「持ち帰りでお願いします。まろやかな汁に、胃にやさしい具を」  
店主「番台、今夜も忙しいか」  
受付「荷待ちの運転手さんに、『二時間だけ寝たい』と言われまして」  
店主「部屋はあったか」  
受付「ありました。ただ、うちの料金表には一泊しかないんです。二人で、しばらく料金表を見ていました」  
店主「どうした」  
受付「一泊分でいい、と。では鍵を、と言ったら、今度は『目覚ましを預かってくれ』と」  
店主「枕元じゃ起きないのか」  
受付「鳴ると、止めて寝てしまうそうなんです。番台で鳴ったら、私が起こしに行く約束でして」  
店主「起こせたか」  
受付「起こしました。鍵を握ったまま、もう一度寝そうになっていましたけど」  

〔ゲーム〕2杯以上のときだけ、次の1行を出す。

受付「番台を代わってくれている者の分も、同じものでお願いします」  

〔ゲーム〕注文は まろやか＋やさしい。判定の結果で、次のうち1つだけ出す。

- **GOOD**　受付「この匂いです。戻ったら、私も温かいうちにいただきます」
- **OK（まろやかは合った）**　受付「汁はありがたいです。具も、胃にやさしいものだと、もっと良かったんですが」
- **OK（やさしいは合った）**　受付「具はよさそうです。汁は、まろやかなものをお願いしたつもりでして」
- **BAD**　受付「すみません。まろやかで、胃にやさしいものをお願いしたんですが……」

〔ゲーム〕会計。

受付「ごちそうさまです。今夜は、目覚ましを持たずに帰れます」  
店主「返したんだな」  
受付「はい。あれが番台にあると、私のほうが眠れなくなりまして」  

## 夜半　雑貨屋の夜番（ニカのあと）

夜番「持ち帰り、頼めるか。店番を代わってもらってる間でな」  
店主「何がいい」  
夜番「苦いのだ。眠気覚ましでな。具はやわらかくて、胃にやさしいのにしてくれ」  
店主「今日は売れたか」  
夜番「売れたよ、まったく。作業灯と延長コードを、まとめて買ってった。旧倉庫で使うんだと」  
店主「あそこ、灯りが足りないのか」  
夜番「そこまでは知らん。買いに来たのは『手元が暗い』って言ってたがな」  
店主「ずいぶん出たのか」  
夜番「棚の奥の箱まで出した。三年寝てた箱だ。箱の絵の男が、まだ有線の電話を持ってる」  
店主「使えるのか、それ」  
夜番「中は出して確かめたよ。売り物だからな。灯りは点いた」  
店主「取り付けにも行ったのか」  
夜番「売るまでがうちの仕事だ。向こうでどうつないだかまでは、見とらん」  

〔ゲーム〕2杯以上のときだけ、次の1行を出す。

夜番「いま店に立ってる奴の分も頼む。同じのでいい」  

〔ゲーム〕注文は 苦い＋やさしい。判定の結果で、次のうち1つだけ出す。

- **GOOD**　夜番「ああ、この苦い匂いだ。具も柔らかそうだな。帰って食うよ」
- **OK（苦いは合った）**　夜番「苦いのはこれだ。具は、もう少しやわらかいのが良かったな」
- **OK（やさしいは合った）**　夜番「具はいい。苦い汁も、欲しかったんだがな」
- **BAD**　夜番「苦い汁に、やわらかい具。そう頼んだつもりだったがな、まったく」

〔ゲーム〕会計。

夜番「戻ったら、空いた棚を拭かんとな。品物があると、奥まで手が入らんのだ」  
店主「また埋めるのか」  
夜番「そのうちな。今夜くらいは、奥の壁が見えるままにしとく」  

## 明け方　夜間清掃員（セティヤのあと）

清掃員「雨を、もう少しここでしのいでいいか。道具は端に寄せる」  
店主「通れるようにしといてくれれば」  
清掃員「助かる。今夜は、段ボールが重くなる前に回りたくてな」  
店主「濡れると持てないか」  
清掃員「持てる。持ったとき、底だけ道に残る」  
店主「今夜もか」  
清掃員「いや。向こうの店が、軒下へ寄せといてくれた。いつもは外に積んである」  
店主「頼んだのか」  
清掃員「頼む前にやってあった。礼を言ったら、荷車が通らないから寄せただけだと」  
店主「置き場が同じだったんだな」  
清掃員「理由は何でもいい。今日は底ごと運べた」  

清掃員「酸っぱい汁に、腹にたまる具を。明るくなるまで、まだ回る」  

〔ゲーム〕2杯以上のときだけ、次の1行を出す。

清掃員「連れの分も同じのを。みんな同じ道を回ってる」  

〔ゲーム〕注文は 酸っぱい＋腹もち。判定の結果で、次のうち1つだけ出す。

- **GOOD**　清掃員「酸っぱい。……いいな。これだけ腹に入れば、次の通りまで持つ」
- **OK（酸っぱいは合った）**　清掃員「この酸っぱさはいい。具は、もう少し腹にたまるのが欲しかった」
- **OK（腹もちは合った）**　清掃員「腹にはたまる。汁は、酸っぱいのを頼んだんだが」
- **BAD**　清掃員「酸っぱくて、腹にたまるのを頼んだ。次は、それで頼む」

〔ゲーム〕会計。

清掃員「ごちそうさん。濡れたのは、こっちの袋でまとめて持ってく」  
店主「気をつけてな」  
清掃員「鍋の灰、まだ熱いだろ。そっちは冷めてからでいい」
