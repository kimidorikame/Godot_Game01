# 『夜湯』5日目・明け方　リン（新人警官）

## この稿について

- **表記の決まり**：`〔ゲーム〕` の行はゲームの処理（表示しない）。「名前「セリフ」」だけを会話枠に出す。ト書きは書かない。
- **話し方**
  - リン：丁寧で生真面目。冗談を真に受けてから、少し遅れて返す。「〜です」「〜ました」。一人称は「私」。
  - 店主：短く受ける。
- 勤務明け。3回目の来店。**今度は店主の方から「昼の仕入れ、どっちを回ればいい？」と聞く。** 2日目の道案内が、ここで返る。
- 1杯。注文は 酸っぱい＋歯ごたえ。好物は米麺。
- 屋台の会話には、裏の立場をにおわせる文を入れない（裏はタイムラインの暗号だけ）。
- 5日目の最後の常連。火事の前の、最後の静かな明け方。

## 本編

### 来店・仕事が終わった人

リン「おはようございます。まだ大丈夫ですか」  
店主「鍋はある。今日は休憩か」  
リン「勤務は終わりました。引き継ぎも済みました」  
店主「今度こそ、おやすみが言えるな」  
リン「それは、帰るときにします」  
店主「覚えてたか」  
リン「一度、言うところを間違えたので」  
リン「商店の方には『おはよう』、夜勤の方には『お疲れさま』で。通りの両側で違うんですね」  
店主「同じ店でも、入れ替わるぞ」  
リン「はい。さっきは同じ方に両方言いました」  
店主「どっちも合ってる」  
リン「その方もそう言って、パンを抱えて帰っていきました」  

店主「椅子は一つでいいな」  
リン「はい。今日は動かしません」  
店主「幅が分かったか」  
リン「椅子では測れないと分かった分は、役に立ちました」  
店主「飯は」  
リン「酸っぱい汁に、噛める具をお願いします。米の麺も、あったらうれしいです」  
店主「眠くないか」  
リン「座ったら、少し。食べながら寝ないようにします」  
店主「寝るなら食い終わってからだ」  
リン「ここでいいんですか」  
店主「帰ってからだよ」  
リン「帰ったら、先に靴下を干します。座る前に」  
店主「まだ濡れてるのか」  
リン「今日は汗です。昨日は帰ってから机の下で脱いで、そのまま寝てしまって」  
店主「起きたときに困るぞ」  
リン「はい。制服を着るより、机の下から探す方が長くかかりました」  

### 提供と反応

〔ゲーム〕1杯。酸っぱい＋歯ごたえ。好物は米麺。判定の結果で、次のうち1つだけ出す。

- **GREAT**　リン「米の麺もありますね。酸っぱくて、噛むものもあって。……勤務の終わりに、これはうれしいです」
- **GOOD**　リン「酸っぱさがいいです。具もしっかり噛めます。歩く方は終わったので、今は食べる方に使います」
- **OK（酸っぱさは合った）**　リン「汁は好きです。具は、もう少し噛み応えがある方をお願いしたかったです」
- **OK（歯ごたえは合った）**　リン「噛み応えはあります。酸っぱい汁で食べるつもりだったので、少し驚きました」
- **BAD**　リン「……酸っぱい汁と、噛み応えのある具をお願いしたんですが。今日は違う方ですね」

### 食事・店主からの道の質問

店主「昼の仕入れ、どっちを回ればいい？」  
リン「市場へ行く道ですか」  
店主「昨日の昼も、帰りに水缶を持って引き返した。今日は先に聞いとく」  
リン「荷車で行きますか」  
店主「ああ。帰りは骨と水を載せる」  
リン「では、いつもの細い角を一つ過ぎて、次で曲がってください」  
店主「少し遠回りだな」  
リン「でも、曲がる所に余裕があります。さっき同じくらいの荷車が、荷を載せて通るところを見ました」  
店主「向こうから来たら、すれ違えるか」  
リン「その場では無理です。角の手前に下がれる場所があります。入る前に、向こうを見てください」  
店主「そこまで見たか」  
リン「はい。私も横を歩きました。入口だけ抜けられても、その先で止まることがあるので」  
店主「水を汲む方へは」  
リン「市場に入ってからは、管理の方の案内を見てください。今朝、箱を動かしていました。そこは変わるかもしれません」  
店主「梁伯の矢印がまた増えるな」  
リン「私の地図も、矢印が増えました」  

店主「見せてみろ」  
リン「ここです。こっちは『徒歩』。こちらには、通っていた荷車の向きも付けました」  
店主「この線、消したのか」  
リン「道はあります。ただ、今夜は待機の車がいて通れなかったので。前の記録と分けています」  
店主「線が消えたら、知らん人には道がないみたいだな」  
リン「なので、消した方にも時刻を残しました。いつ確認したか、自分でも忘れないように」  
店主「昼まで同じかは分からんか」  
リン「はい。今見た状態です。行く前にも、角を見てください」  

### 食事・人の歩く速さ

店主「昨日より話が細かくなったな」  
リン「運ぶ人に聞くことが増えました。幅だけでなく、何を載せているかも」  
店主「重いと止まれんからな」  
リン「荷車を下り坂へ案内しようとしたら、先に持ち手を握ってみろと言われました」  
店主「握ったか」  
リン「平らな所で、支えるのを手伝いました。少し傾いただけで、腕へ重さが来るんですね」  
店主「支給の補助でも分かるか」  
リン「支えられることと、楽に運べることは違いました。ずっと握っている指までは、勝手に休みません」  
リン「その方、最初はまた荷をどけろと言われると思ったそうです」  
店主「制服で来れば、そう見える」  
リン「私が持ち手を握ったら、今度は離していいか、と」  
店主「急に渡されたか」  
リン「いえ。私が持ったと言うまで、支えてくれました。受け渡すだけでも、順番があるんですね」  
店主「手が塞がってる分、声をかけるんだよ」  
店主「うちの水も、半分持つか」  
リン「……勤務が終わってから、次の仕事が来ました」  
店主「冗談だ。今日はもう帰れ」  
リン「はい。今は、分かりました」  

リン「巡回で同じ所へ戻るたび、待っている人だけ替わっていました」  
店主「荷は動いてるか」  
リン「少しずつ。でも、空いた場所へ次が入るので、列の終わりは近くならなくて」  
店主「ずっと同じ景色に見えるな」  
リン「はい。だから、顔を見てから声をかけるようにしました。さっき説明した方とは限らないので」  
店主「相手からすりゃ、あんたはずっといる」  
リン「『さっきも警官に聞いた』とは言われました。私ではなかったんですが」  
店主「同じ制服だからな」  
リン「同じ説明ができるように、引き継ぎにも書きました」  
店主「勤務は終わったんだろ。地図、出しっぱなしにするなよ」  
リン「今、消しました。時計も」  
店主「今日は確認し直さんのか」  
リン「しません。……看板の文字が、こんなに少なかったんですね」  
店主「いつもこれだけだ」  
リン「ここまで、自分の書いたものを一緒に見ていたんですね。少し、目を休ませます」  

### 会計・退店

〔ゲーム〕会計（1杯分）。

リン「地図の印、端末へ送ってもいいですか。荷車で通った方の道だけ」  
店主「頼む。いつ見たかも付けとけ」  
リン「はい。今朝の確認、と入れました」  
店主「最初は俺が道を描いたのにな」  
リン「一本目は、今も残してあります。氷の水が流れる方です」  
店主「もう靴を濡らして確かめるなよ」  
リン「今日は避けました。……ごちそうさまでした。おやすみなさい」  
店主「ああ、おやすみ」  
リン「……旧倉庫の方が、今夜は明るいですね」  
店主「ここから見えるのか」  
リン「倉庫通りの先、曲がり角の所です。昨日は、手前の灯りしか見えなかったので」  
店主「灯りを足したんだろ」  
リン「はい。……足しすぎて、かえって影が濃く見えます。では、失礼します」  



## 実装メモ

| 項目 | 内容 |
|---|---|
| 注文 | 酸っぱい＋歯ごたえ（データのまま）。好物は米麺（4日目に伝え済み）。 |
| 分かること | リンが、荷を載せた荷車が通るのを自分で見た道を教える。「今朝の確認」と時刻を付ける。昼まで同じとは限らない。 |
| 表と裏 | 屋台では、2日目に道を聞いた新人が、道を教える側になる温かい場面。同じ日の暗号では「屋台との接触を継続する」。親切は本物で、その知識が別の相手にも渡っている。 |
| 不安の出し方 | 「待っている人だけ替わっていました」「列の終わりは近くならなくて」。退店の「旧倉庫の方が、今夜は明るいですね」「足しすぎて、かえって影が濃く見えます」。 |
| 火事の前の晩 | 最後の5行は、火事（6日目の夜）の前に、旧倉庫の灯りが増えていることを店主とプレイヤーに見せる。原因には触れない。雑貨屋の作業灯（3・4日目）とつながる。 |
| つながり | 「おやすみなさい」＝2日目の「言ってみたかっただけです」「仕事が終わってから言いな」。「一本目は、氷の水が流れる方」＝2日目。「椅子では測れない」＝4日目。 |
| たたき台から変えた所 | 退店に、旧倉庫の灯りの5行を足した。たたき台の「閉店の短い共通場面」（店主の独り言）は、閉店の場面の仕組みが無いので外した。 |
| 道を端末へ送る話 | 会話の上だけ。地図の画面や道を選ぶ仕組みは足さない。 |
| 今回の加筆 | 明け方の挨拶、帰宅後の靴下、荷車の持ち手を受け渡す声かけ、視覚表示を消したあとの看板。裏の立場を屋台の会話には出さない。退店の灯りは見えた場所を限定し、3・4日目から倉庫で照明が使われていたことと両立させた。 |
| あとで足すもの | 具だくさんの一言、断ったときの一言。 |
