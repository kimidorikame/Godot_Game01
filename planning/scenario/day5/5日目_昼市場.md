# 『夜湯』5日目　昼市場（張姐・サミル・羅文・梁伯）

## この稿について

- **表記の決まり**：`〔ゲーム〕` の行はゲームの処理（表示しない）。「名前「セリフ」」だけを会話枠に出す。ト書きは書かない。
- **流れ**：市場に着く → 張姐（必須）→ 仕込む量を選んで出汁を買う → 買い物（サミル・羅文は寄った人だけ）→ 市場を出るときに梁伯（必須）。
- 雨は降っていない。新しい効果（値上げ・品切れ・断水など）は足さない。
- **話し方**
  - 張姐：早口でたたみかける。最後は質問で締める。店主を「アンタ」と呼ぶ。
  - 梁伯：命令と説教。同じことを二度言う。「〜しな」「〜とる」。
  - サミル：無口。短い言葉で話す。手は止めない。
  - 羅文：物静か。味の話になると長くなる。自分の仕入れすぎは小声になる。
  - 店主：短く受ける。
- **この場面で伝えること**
  - 張姐：迂回先がいっぱいで、荷が旧倉庫へ回される。空箱を取りに来る車が入れない。窓口の変更の案内が紙で届いた（必ず通る）。
  - 梁伯：旧倉庫側の夜の水の数字が、昼を越えた（必ず通る）。

## 張記肉類加工　張姐　※市場に着いたとき

張姐「こっち。箱の向こうよ。今日は売り場を畳んだんじゃないからね」  
店主「箱屋になったかと思った」  
張姐「なってたら、今ごろ全部売ってる。空いたのを返したいのに、取りに来る車が入れないのよ」  
店主「積んで帰る場所がないか」  
張姐「荷を避けるために置いた荷が、また別の荷を避けてきたんだって。もう何を待ってる列なのか、聞かないと分からない」  
店主「その札、箱に貼らないのか」  
張姐「貼ったら箱ごと持ってかれたの。返す場所の札まで返してどうすんのよ」  
店主「今度は柱か」  
張姐「動かない所。荷台で隠れない高さにもした。私の顔より先に、こっちを見てほしいわ」  
店主「骨は」  
張姐「着いてる。先に冷やす分だけ受け取った。そこは後回しにできないでしょ」  
店主「迂回先もいっぱいだってな」  
張姐「運転手も言ってた。行ったら置けなくて、旧倉庫へ回れって。曲がる場所まで戻るのに、また待ったってさ」  
店主「同じ荷で何度も走るな」  
張姐「走れりゃまだいいよ。止まってる間、冷やす機械だけ動いてるんだから」  
張姐「旧倉庫の中も、冷やす機械だらけだってさ。うちの運転手、床の延長の線を三本またいだって。電気、足りてるのかね？」  
店主「俺に聞くな」  
張姐「聞いてないよ。言いたかっただけ」  
店主「請求先は、今日も違う名前か」  
張姐「運ぶ方の窓口のこと？　今日は変更の案内が来た。ようやく紙が追いついたわ」  
店主「端末にも来たか」  
張姐「来たよ。同じのが何通も。宛先の部署だけ変えてね」  
店主「読んだ印は付けたのか」  
張姐「付けた。でも読んだのと、払うって決めたのは別。そこは返事にも書いといた」  
店主「返す字も増えるな」  
張姐「骨の量なら一言で済むのにね」  
店主「前の分も、そっちへ払うのか」  
張姐「そこは確認中。新しい名前が来たからって、古い請求書を捨てるわけにいかないでしょ」  
店主「二つとも置いとくか」  
張姐「受け取った日を書いてね。あとは返事をもらってから。アンタの骨の勘定は、うちでいいよ」  
店主「そこまで替わったら困る」  
張姐「替えないよ。昨日のだし、どうだった？」  
店主「よく出た」  
張姐「なら、今日もこっち。袋を開けて。……その前に箱を踏まない。で、今日はどれ位仕込む？」  

〔ゲーム〕仕込む量を選んで、出汁を購入。

店主「箱、もう少し寄せるか」  
張姐「そこまででいい。戻ってきた台車の場所を残すの。何も置いてないからって、空いてるわけじゃないんだから」  

## 炭屋　サミル　※寄った人だけ（店ごとの会話の仕組みができたら）

サミル「……袋、そこ。縫い終わる」  
店主「新しい袋じゃないのか」  
サミル「新しい炭を入れる袋。穴は前からある」  
店主「糸まで黒いな」  
サミル「白いので縫っても、すぐ同じになるよ」  
店主「針、指に当たらんか」  
サミル「ここを使う」  
店主「その革か」  
サミル「古い手袋。まだ硬い所が残ってた」  
店主「よく取っとくな」  
サミル「探さずに済む」  
店主「台車の車輪は、まだ替えてないか」  
サミル「探してる。外の大きさが同じでも、軸の太さが違うんだ」  
店主「腰の補助で運べるだろ」  
サミル「持ち上げるときは助かる。でも、角で車輪が引っかかるたびに持ち上げたくない」  
店主「今は角も多いしな」  
サミル「昨日、袋を一つ下ろして、台車を向け直して、また載せた。腰は平気でも、袋の方が擦れる」  
店主「それで縫ってるのか」  
サミル「そう。袋には補助が付かないから」  
店主「縫い目、きれいだな」  
サミル「裏を見るなよ」  
店主「売る方もそう言うか」  
サミル「中身は見ていい」  
店主「俺の分は」  
サミル「大きい炭と小さい炭、分けて入れてある。取り出すときに底から掻き回さなくていいように」  
店主「手間だな」  
サミル「ここは座ってできる。あんたは夜、立ってやる」  
店主「助かる」  
サミル「……袋の下も持て。糸が新しいうちは、穴の場所が分からん」  


## 南興乾貨行　羅文　※寄った人だけ（店ごとの会話の仕組みができたら）

羅文「瓶を開けるなら、こっちから。そっちは戻す前の匂いだ」  
店主「乾いたままじゃ分からんか」  
羅文「分かることはある。ただ、椀に出すのはそっちじゃないだろ」  
店主「今日も試してるのか」  
羅文「仕入れ先が替わった。同じ札だったから、少しだけ戻してみた」  
店主「違ったか」  
羅文「戻るまでが少し長い。噛んだ感じも違う。悪くはない」  
店主「きくらげか」  
羅文「ああ。いつもの時間で上げると、客がずっと噛むことになる」  
店主「歯ごたえを頼む客はいるな」  
羅文「それでも、食い終われた方がいい」  
店主「売り物を食ってばかりだな」  
羅文「一口ずつだ。戻す前は軽いからと、いっぺんに試すと夕飯が入らなくなる」  
店主「今日もか」  
羅文「……今日は、その予定で来た」  
店主「味付けは」  
羅文「まずは何も付けずに。あとで魚醤を少し。濃い汁に入れるなら、噛み終わったあとに何が残るかも見る」  
店主「一口の話が長いな」  
羅文「そこを決めてから、売るんだよ」  
店主「札には書かないのか」  
羅文「今、書いた。袋にも入れとく。端末の説明だけだと、鍋の前まで持っていかん人がいる」  
店主「俺のことか」  
羅文「紙なら、見るだろ」  
店主「鍋の横へ置く」  
羅文「濡れない所にな。……一袋でいいか」  
店主「いつもどおりでいい」  
羅文「そうしな。俺はもう少し試す」  
店主「どれだけ仕入れた」  
羅文「……棚の奥にもある」  


## 共同水場　梁伯　※市場を出るとき

梁伯「その取っ手、もう一方も起こしな。片方だけじゃ、傾く」  
店主「まだ水は入ってない」  
梁伯「入ってから直すより、今だよ」  
店主「線が太くなったな」  
梁伯「昨日の線の上に水缶を置く者がおった。だから、こっち側だと矢印も足した」  
店主「矢印の上へ置かれるぞ」  
梁伯「もう置かれた。どけさせた」  
店主「早いな」  
梁伯「一つ置けば、その後ろに並ぶからな。最初の一つをどかす方が早い」  
店主「旧倉庫の方は」  
梁伯「昨夜も使っとる。直した留め具からは、見た時には落ちとらんかった」  
店主「夜の分まで、いつ見てるんだ」  
梁伯「夕方と朝。前の数字も残しとる。数字を見た時刻もな」  
店主「書く場所、まだあるか」  
梁伯「新しい帳面を出した。古いのも、そこだ」  
店主「こんなに溜めてたのか」  
梁伯「昨日とだけ比べとったら、昨日がおかしかった時に分からんだろ」  
梁伯「夜中の数字が、とうとう昼を越えた。昼を越えたんだ。この水場を見てきて、初めてだよ」  
店主「それでも水は出るか」  
梁伯「使う者が来るからな。水を汲んだ帰りに荷車をよけて、また蓋を外してた」  
店主「何で外す」  
梁伯「こぼれたか、中を確かめたかったか。そこまでは聞いとらん。閉めて持てとは言った」  
店主「今日はどっちから帰るかね」  
梁伯「ここを出たあとの道は、さっきと変わっとるかもしれん。水缶を持ったまま、狭い所へ先に入るなよ」  
店主「下ろす場所を見てからか」  
梁伯「そうだ。引き返す時にも置く所が要る。あんたの鍋も、水だけ歩いて帰ってはくれんからな」  
店主「ほら、へこみまで来た」  
梁伯「止めな。……今日は、先に気づいたな」  
店主「毎日言われるからな」  
梁伯「じゃ、蓋も」  
店主「閉めたよ」  

〔ゲーム〕払うのは、いつもの日の分だけ（3・4日目と同じ形）。


## 実装メモ

| 項目 | 内容 |
|---|---|
| 張姐 | 5日目の市場の場面。「で、今日はどれ位仕込む？」は仕込む量を選ぶ場面の文。選んだあとに2行ある。 |
| 梁伯 | 市場を出るときの場面。払い方と額は変えない。帰りの道は教えない（今夜リンに聞く動機を残す）。 |
| サミル・羅文 | 店ごとの会話の仕組みはまだ無い。必ず伝える情報は入れていない。暮らしの会話。羅文の仕入れ先の変更は、曜海聯運とは結びつけない。 |
| 必ず伝える情報 | 迂回先が埋まり、旧倉庫へ荷が集中している／発注の窓口の変更が、紙の案内として表に出た。 |
| 不安の出し方 | 張姐「何を待ってる列なのか、聞かないと分からない」「床の延長の線を三本またいだって。電気、足りてるのかね？」。梁伯「夜中の数字が、とうとう昼を越えた」。どちらも見聞きしたことだけ。 |
| 火事の手がかり（両方に読める） | 張姐の「延長の線」は事故の側。又聞きで、張姐自身は見ていない。 |
| 今回の加筆 | 返却場所の札と重複する通知、サミルの針仕事、羅文の試食、梁伯の水量の記録。商売を回す手つきと各人の口調を足した。値段・在庫・調理操作は変えない。 |
| たたき台から足した所 | 張姐の延長の線の3行、梁伯の「昼を越えた」の1行。サミルの口調を1日目の無口に寄せた。 |
