# 『夜湯』5日目・夜半　ニカ（配信者）

## この稿について

- **表記の決まり**：`〔ゲーム〕` の行はゲームの処理（表示しない）。「名前「セリフ」」だけを会話枠に出す。ト書きは書かない。
- **話し方**
  - ニカ：16〜17歳。早口で、話題が次へ跳ぶ。「え、待って」「〜くない？」「〜ってこと？」「〜なんだよね」。一人称は「私」。自分がどう見えているかを、自分で口に出す。
  - 店主：短く受ける。分かることと、分からないことを分けて答える。
- 2回目の来店。4日目に撮った映像を2本見せる。1本は旧倉庫への搬入。もう1本は、新しい窓口の事務所の前で、受付の人が組の上着の男と話している所。
- **店主が、映像の男を「レックスのところの兄貴分」と見分ける。** ニカが男の素性を知るのは、このとき。
- 1杯。注文は まろやか＋歯ごたえ。好物は海老。
- 今夜は、放火の噂も、火事の気配も出さない（火事は6日目の夜）。

## 本編

### 来店・見せたいもの

ニカ「来れた。今日は港まで下りてない」  
店主「下りたくなくなったか」  
ニカ「昼に行ってきた。今はご飯。あと、見せたいのがある」  
店主「座ってからにしろ」  
ニカ「うん。……その前に、端末ちょっと置いていい？　鞄の中、充電の線が絡まっちゃって」  
店主「椀を置く場所は空けろよ」  
ニカ「ここなら平気。これ、紫の線だけ見つければ、するっと出るはずなんだけど」  
店主「出たか」  
ニカ「全部出た」  
店主「ほどけてないな」  
ニカ「買うとき、色は揃えたんだよね。長さは揃えなかった。そこ大事じゃなくない？　って思ってた」  
店主「使う線だけ出せ」  
ニカ「それはできる。使い終わった線を、別にしまうのが苦手なんだよね」  
店主「同じ鞄へ入れるからだ」  
ニカ「小さい袋も買ったよ。今、その袋の中で絡まってる」  
店主「部屋を狭くしただけか」  
ニカ「でも鞄からは一回で出せた。そこは、進んだと思う」  

店主「今日は何にする」  
ニカ「前の白くてまろやかな汁。こりこり噛める具も。今夜は、まず食べたい」  
店主「海老は」  
ニカ「いたら、すごくうれしい。あれは噛むのとは別に好き。最後まで取っときたいんだよね」  
店主「最後まで冷ますなよ」  
ニカ「じゃあ、最後の一つ手前。……言ったら、もう食べたくなった」  

### 提供と反応・撮影

〔ゲーム〕1杯。まろやか＋歯ごたえ。好物は海老。判定の結果で、次のうち1つだけ出す。

- **GREAT**　ニカ「海老いる。白いのも、こりこりも。……今夜の私、注文がうまかった気がする」
- **GOOD**　ニカ「これ。まろやかで、噛む方もちゃんとある。今日ずっと、こんな椀が欲しかった」
- **OK（まろやかは合った）**　ニカ「汁は好き。具も、もうちょっとこりこりしててほしかったな」
- **OK（歯ごたえは合った）**　ニカ「噛む方はこれだよね。白くてまろやかな汁で、食べるつもりだった」
- **BAD**　ニカ「……あれ。前みたいに、まろやかなのと、こりこりって頼んだんだけど」

ニカ「食べる前に、一枚だけ撮っていい？　椀だけ」  
店主「いいよ」  
ニカ「……撮った。はい、終わり。いま録画も切ってる」  
店主「今日は早いな」  
ニカ「もう、目が疲れちゃって。昨日の暗所補正、長く使いすぎた」  
店主「見せるのは、あとでもいいぞ」  
ニカ「大丈夫。端末の明るさ、落としてきた。……待って、先に一口」  
ニカ「最初は、夜中にお店が開いてるだけで嬉しかったんだよね」  
店主「飯を食う人がいるからな」  
ニカ「今は、看板が消えたあとも人が出てこない店が気になる。片づけしてるんだって、やっと分かった」  
店主「閉めた瞬間には帰れんよ」  
ニカ「うん。私、光ってる時間だけ撮って、街がずっと元気だと思ってた」  


### 食事・旧倉庫の映像

ニカ「昨日、旧倉庫の門まで撮れたんだ」  
店主「あそこまで行ったか」  
ニカ「荷札の名前、曜海聯運だった。社名で事務所を調べて、そのあと搬入の方を見に行った」  
店主「雨粒の先が読めたか」  
ニカ「全部は無理だったけど、別のコマに残ってた字を合わせて、候補を探した。事務所の看板と、読めたとこは同じだった」  
店主「これが旧倉庫か」  
ニカ「うん。車が入ると、この灯りが隠れるの。もうちょっと先……ここ」  
店主「車は多いな」  
ニカ「門が閉まる前に次が来る。もう開けっぱなしにすればいいのにって思ったくらい」  
店主「中は見えたか」  
ニカ「荷台の後ろまで。箱の中は見えない。何を運んでるかは、これじゃ分かんない」  
店主「声は」  
ニカ「エンジンの音が強い。聞き返してたら、宿の人に音を下げてって言われた」  
店主「港が見える部屋で、港の音を流すなよ」  
ニカ「窓は壁だったから。……でも下げた。私のだけ二重になるもんね」  
ニカ「でも、音で分かることもあった。私が門の看板を撮ってる間にも、車がずっと来てた」  
店主「画面の外か」  
ニカ「うん。編集で切ると、来てない時間みたいになるんだよね」  
店主「長いまま見せるか」  
ニカ「全部は眠くなるよ。……私も一回寝た。残すところ、難しい」  

### 食事・事務所前の男

ニカ「もう一本。こっちは昼。窓口の事務所の前」  
店主「中へ入ったのか」  
ニカ「外から。看板を撮ってたら、受付にいた人が出てきて、この人と話し始めた」  
店主「少し戻せ」  
ニカ「ここ？　上着、赤茶色の」  
店主「……レックスのところの兄貴分だな」  
ニカ「え、待って。知ってる人？」  
店主「顔は知ってる。この辺の組の人間だ。上着の金のところも、いつものだな」  
ニカ「レックスっていうのは」  
店主「うちへ場所代を取りに来る若いの。こいつは、その上の男だ」  
ニカ「じゃあ、その組が窓口をやってるってこと？」  
店主「そこは知らん。俺が知ってるのは、映ってる男の方だ」  
ニカ「……そっか。同じ所に立ってるだけで、そこの人とは限らないよね」  
店主「何を話してた」  
ニカ「聞こえてない。道の反対側だったし。手に端末を持ってるけど、画面も見えない」  
店主「何か頼みに来たのかもしれんな」  
ニカ「仕事を取りに？」  
店主「用事までは分からんよ」  
ニカ「でも、誰かは分かった。そこ、ずっと止まってたんだよね」  

### 食事・撮れたものの重さ

ニカ「名前が一文字だったのが、会社になって、建物になって。そこに来る人まで見えた」  
店主「よく歩いたな」  
ニカ「うん。歩いた分、ちゃんと増えてる。宿で拡大してるだけじゃ、見つからなかった」  
ニカ「最初に上げた車の列も、思ったより見られてるんだよね」  
店主「遠くの人か」  
ニカ「近くの人も。『いつもの道なのに、こんなに並んでたんだ』って返事があった」  
店主「通ってても、全部は見てないだろうな」  
ニカ「自分が見てきたものを、人も見てくれたって感じがする。……今、うれしそうに喋ってるよね、私」  
店主「喋ってるな」  
ニカ「うん。うれしいんだと思う。次は、見て分かるところまで持っていきたい」  
店主「帰り道は分かったか」  
ニカ「……そっちは増えてない。事務所から出たあと、同じ看板を二回見た」  
店主「戻ってきたか」  
ニカ「二回目で気づいた。明るい色の看板って覚え方、駄目だね。広告が替わるし」  

ニカ「これ、一本にしたら、みんな分かるかな」  
店主「何を」  
ニカ「ストで止まってる場所と、動いてる場所があること。窓口の名前まで替わってること」  
店主「映ってる分は見えるだろ」  
ニカ「言葉も付けないと、また港のきれいな動画になる。私も最初、そういうのを見て来たし」  
店主「今日は何て付ける」  
ニカ「まだ決めてない。……でも、誰がどこへ仕事を頼み始めたか、そこが分かれば、一本になる気がする」  
店主「依頼を見てみるか」  
ニカ「配達の一覧？　そうだ、表に出てるのもあるよね。いつから名前が出てるか、帰ったら探す」  


### 会計・退店

店主「椀、置きっぱなしだぞ」  
ニカ「あ。……食べる。昨日の画面見てたら、また今夜の汁が冷めるところだった」  
店主「まだ温かい」  
ニカ「うん。残りはこっちを見る。端末、裏返す」  

〔ゲーム〕会計（1杯分）。

ニカ「ごちそうさま。今日の分、忘れないうちに書いとく」  
店主「歩きながらやるなよ」  
ニカ「宿で。音も下げる。……あの人のこと、教えてくれてありがと」  
店主「顔を知ってただけだ」  
ニカ「それでも、私には分かんなかったんだよ。じゃ、またね」  



## 実装メモ

| 項目 | 内容 |
|---|---|
| 注文 | まろやか＋歯ごたえ（データのまま）。手がかり：「前の白くてまろやかな汁。こりこり噛める具も」。朝のDMの「白い汁」。 |
| 好物 | 海老。「いたら、すごくうれしい」。海老はごちそうの具で、歯ごたえの代わりにはならない。 |
| 分かること | 荷札の社名は曜海聯運。事務所の看板と同じ。旧倉庫へ車が次々入る（箱の中は見えない）。事務所の受付の人と、兄貴分が話していた（声は聞こえない）。 |
| 店主が言うこと・言わないこと | 言う：映っている男は、レックスの上にいる男。この辺の組の人間。／言わない：組が窓口をやっているかどうか、何の用で来たか。「そこは知らん。俺が知ってるのは、映ってる男の方だ」。 |
| 6日目への仕込み | 「歩いた分、ちゃんと増えてる」＝うまくいった手応え。「誰がどこへ仕事を頼み始めたか、そこが分かれば、一本になる気がする」＝6日目に公開の依頼一覧を調べる動機。この手応えが、6日目に推測を言い切ってしまう下地になる。 |
| 4日目に阿強が話したこと | 阿強の「届け先は旧倉庫、受領の名義も曜海聯運」は、店主とプレイヤーだけが知っている。店主はニカに教えない。 |
| 暮らしの部分 | 絡まった充電の線（色は揃えた、長さは揃えなかった）、宿で音を下げてと言われた、同じ看板を二回見た。 |
| コマの候補 | 端末の映像2本（門へ入る車／事務所の前の二人）。無くても、セリフだけで分かるようにしてある。 |
| たたき台から変えた所 | 口調を少し足した（「え、待って」など）。筋は変えていない。 |
| 今回の加筆 | 充電線の片づけ方、看板が消えたあとの店、映像を残す長さ、投稿への反応を喜ぶニカ。撮影と取材が進む手応えを足し、6日目の飛躍につなぐ。兄貴分の用件や窓口の運営者は確定させない。 |
| あとで足すもの | 具だくさんの一言、断ったときの一言。 |
