# 『夜湯』4日目・明け方　ターニャ婆（老婆）

## この稿について

- **表記の決まり**：`〔ゲーム〕` の行はゲームの処理（表示しない）。「名前「セリフ」」だけを会話枠に出す。ト書きは書かない。
- **話し方**
  - ターニャ婆：「〜だよ」「〜かい」「〜おくれ」「〜しな」。物の話は細かい。見たことと、見ていないことを分けて話す。一人称は「あたし」。
  - 店主：短く受ける（婆の「〜かい」は使わない）。
- 雨上がり。荷解きの時刻がずれて、段ボールを拾える時刻が読めなくなった晩。帰り際に、高台の空き駐車場の話をする。
- 1杯。注文は うましお＋腹もち。好物はモツ（4日目は市場で買えるので、初めて GREAT を狙える）。
- 瓶の受け渡しは7日目。

## 本編

### 来店・段ボール

ターニャ婆「それ、敷くのかい」  
店主「足元がまだ湿ってる。箱を一枚つぶそうと思ってな」  
ターニャ婆「下、触ってごらん」  
店主「乾いてるぞ」  
ターニャ婆「押してみな」  
店主「……硬いな」  
ターニャ婆「そっちはまだ売れる。敷くならこっち。端がふやけて、もう箱には戻らないよ」  
店主「上は同じに見えるがな」  
ターニャ婆「持ち上げる人は底も見るんだよ。中身ごと落としたくないだろ」  
店主「今日は紙が多いな」  
ターニャ婆「多いけど、半分は濡れてる。荷台が埋まっただけじゃ、稼いだことにはならないね」  
店主「その乾いた方、持ってくか」  
ターニャ婆「もらうよ。紐は切らずに抜いておくれ。まだ縛れる」  
店主「結び目、よく解けるな」  
ターニャ婆「濡れたまま引っ張らなきゃね。固くしたのは大抵、急いだ手だよ」  
店主「俺か」  
ターニャ婆「あんたはまだ切ってないから、今日は違う」  
店主「今日は、が余計だ」  
ターニャ婆「刃物を持つ手は早いからねえ」  
店主「注文より先に仕事か」  
ターニャ婆「あんたが足を載せる前に、言っとかないとね」  

### 注文

ターニャ婆「一杯おくれ。魚醤の、干した根っこの匂いがする方。腹にたまる具もね」  
店主「いつものだな。モツは」  
ターニャ婆「あるなら、うれしいねえ。あれを噛んでる間は、少しゆっくりできる」  
店主「座ってる間は、ずっとゆっくりしてろ」  
ターニャ婆「そうしたいよ。今日は拾える時刻が、なかなか決まらなくてね」  

### 提供と反応

〔ゲーム〕1杯。うましお＋腹もち。好物はモツ。判定の結果で、次のうち1つだけ出す。

- **GREAT**　ターニャ婆「モツも入れたんだね。いい匂いだ。……これは、急いで飲んじまうのがもったいない」
- **GOOD**　ターニャ婆「そう、このたれだよ。腹にもたまる。これで朝の分まで働けるね」
- **OK（うましおは合った・腹もちが外れた）**　ターニャ婆「汁はいいね。具はもう少し、腹に残るのが欲しかったよ」
- **OK（腹もちは合った・うましおが外れた）**　ターニャ婆「腹は満ちそうだね。あの魚醤の匂いがあれば、もっとよかった」
- **BAD**　ターニャ婆「おや、今日は違う方が来たね。いつもの、魚醤で腹にたまるのがよかったよ」

### 食事・荷解きの時刻

店主「いつもの時間に出なかったのか」  
ターニャ婆「夕方に行ったら、まだ箱の中身が入っとった。もう一回回ったら、今度は車から下ろしてるとこ」  
店主「待ったか」  
ターニャ婆「待ってる間に、缶の方を先に回ったよ。戻ったら、乾いた紙は先に持ってかれてた」  
店主「遅かったか」  
ターニャ婆「あたしが早く来たら、誰かが遅かったことになる。そこは順番さ」  
店主「明日は遅く出るか」  
ターニャ婆「それをやると、次は早く荷が着くんだよ。もう少し様子を見ないとね」  
店主「毎回回るのも骨だな」  
ターニャ婆「だから、まとめて置いといてくれる人に聞くんだ。『荷が来たら』じゃなくて、『箱が空いたら』教えとくれって」  
店主「返事は来るか」  
ターニャ婆「忙しけりゃ来ない。来たら行く。来なけりゃ、自分の足で見るだけだよ」  
店主「端末も濡らすなよ」  
ターニャ婆「こっちは乾いてる。昨日、缶より先に袋に入れたからね」  
店主「字はちゃんと読めるか」  
ターニャ婆「相変わらず小さいよ。だから返事は声で送る。いちいち荷台を止めて、あの字をつついてられない」  
店主「声もよく拾うのか」  
ターニャ婆「缶の音まで入るね。『今行く』より、がらがらの方が長い」  
店主「着く前から分かるな」  
ターニャ婆「この間は、近いなら直接言えって返ってきた」  
店主「近かったのか」  
ターニャ婆「店の裏だった。回り込むより早いと思ったんだよ」  

### 食事・若いのの写真

ターニャ婆「阿強は来たかい」  
店主「さっきな。車体の写真を見せられた」  
ターニャ婆「あたしには、ブレーキの写真が来たよ。これの替えが出たことあるかって」  
店主「聞いてたか」  
ターニャ婆「出たことはある。でも今あたしが持ってるわけじゃない。そこは別だって返した」  
ターニャ婆「写真に指を入れろとも送ったよ。大きさが分からないから」  
店主「定規じゃないのか」  
ターニャ婆「本当に合わせるときは定規さ。遠くからちっちゃく写した写真を、先にどうにかしろって話」  
店主「若いのに撮り直しが多いな」  
ターニャ婆「欲しい車体を丸ごと見せたいんだろうね。あたしに見せたいのは、部品だと言いながら」  
店主「お前も、全部見たか」  
ターニャ婆「見たよ。いい色だね、と返したら、そっちにばっかり返事が来た」  
店主「そこまで来たか」  
店主「欲しい物だけはよく見るな、あいつ」  
ターニャ婆「前の補助器も、そうやって型を覚えたんだよ。何でも同じだと思ってたら、見つからないさ」  
店主「見つけた方も、覚えてたな」  
ターニャ婆「欲しいって何度も言われりゃ、覚えるよ。あんたの小さいお玉だって、もう見落とさない」  
店主「今はある」  
ターニャ婆「じゃ、また袋の底へ入れないことだね」  

### 高台の柵と照明

ターニャ婆「上の空き駐車場、柵が付いたね」  
店主「坂の上の、出口に近い方か」  
ターニャ婆「そう。灯りも付いた。今日は下の角から、向こうの白い線が見えたよ」  
店主「あそこ、暗かったろ」  
ターニャ婆「前は車止めの影を踏みそうになった。今度は地面がよく見える」  
店主「人はいたか」  
ターニャ婆「見える所には、いなかったね。灯りだけが点いてる。誰も立ってない所を、あんなに明るくしてどうするんだか」  
店主「荷でも置くのか」  
ターニャ婆「看板までは見てないよ。柵と灯りを見ただけさ」  
店主「いつ付けたんだろうな」  
ターニャ婆「このところ、あたしは下ばっかり回っとったからね。付けてるところは見てない」  
店主「回り道するには、坂がきついぞ」  
ターニャ婆「梱包材が出るなら、回ってみるさ。空の荷台で上れる順にすればいい」  
店主「先に上か」  
ターニャ婆「まだ決めちゃいないよ。何が出るかも見てないんだから」  
店主「こっちの箱は、出る時刻が遅くなった」  
ターニャ婆「そう。あっちは灯りが付いた。明日は、坂の下からもう一回見てみようかね」  

### 会計・瓶・退店

〔ゲーム〕会計（1杯分）。乾いた段ボールは会話の上だけで渡す。売り買いの仕組みは足さない。

店主「瓶もある。持ってくか」  
ターニャ婆「まだいい。溜まったら取りに来る」  
店主「今日は荷台が埋まってるか」  
ターニャ婆「紙の上へ瓶を積むと、帰りに割る。あんたの箱で乾かしといておくれ」  
店主「口は上にしてある。乾いたのからしまうよ」  
ターニャ婆「じゃ、頼んだよ。……おや、その小さいお玉、どこへ置いた？」  
店主「鍋の横だ」  
ターニャ婆「ならよし。あたしの荷台から探すより早い」  
店主「また腹が減ったら来い」  
ターニャ婆「減るよ。そこだけは、予定どおりだからね」  
ターニャ婆「……今夜は車が途切れないね。いつもなら、この時間は猫の方が多いのに」  
店主「数えてたのか」  
ターニャ婆「数えちゃいないよ。静かな晩を覚えてるだけさ」  



## 実装メモ

| 項目 | 内容 |
|---|---|
| 注文 | うましお＋腹もち（データのまま）。手がかり：「魚醤の、干した根っこの匂いがする方。腹にたまる具もね」。 |
| 好物 | モツ。手がかり：「モツは」「あるなら、うれしいねえ」（1日目の「モツが入ってりゃ言うことない」の続き）。モツはスタミナの具で、腹もちの代わりにはならない。GREAT は、薬膳ナンプラーだれ＋腹もちの具＋モツ。 |
| 分かること | 荷解きが夜にずれ、紙を拾える時刻が読めない。高台の空き駐車場に柵と照明が付いた（誰のものか、何を置くかは見ていない）。 |
| 不安の出し方 | 「灯りだけが点いてる。誰も立ってない所を、あんなに明るくしてどうするんだか」。退店の「今夜は車が途切れないね。いつもなら、この時間は猫の方が多いのに」。 |
| リンの暗号との関係 | 同じ晩の 21:25 の暗号に「高台の空き地に灯り。巡回の割り当てなし」がある。婆が話すより前の時刻。暗号を読んだ人には、リンが先に灯りを確認し、確認した担当表では高台に巡回の割り当てがないと分かる。「警察の誰も見ていない」「常に巡回がない」までは意味しない。 |
| つながり | 段ボールの底を押す＝改訂版の「そっちはまだ売れる。敷くならこっち」。小さいお玉＝1日目。阿強のブレーキの写真＝同じ晩の阿強。瓶「溜まったら取りに来る」＝7日目。 |
| たたき台から変えた所 | 高台に「人はいたか」の2行、退店に車の音の3行を足した。たたき台の「閉店の短い共通場面」（店主の独り言2行）は、閉店の場面の仕組みが無いので外し、車の音は婆の退店に入れた。 |
| 今回の加筆 | 紐を解く手、缶の音が入る音声返信、阿強との車体写真のやり取り。高台に人がいないという話は、下の角から見えた範囲に限った。 |
| あとで足すもの | 具だくさんの一言、断ったときの一言。 |
