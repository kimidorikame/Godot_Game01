# 『夜湯』7日目　昼市場（張姐・海叔・ミン・梁伯）

## この稿について

- **表記の決まり**：`〔ゲーム〕` の行はゲームの処理（表示しない）。「名前「セリフ」」だけを会話枠に出す。ト書きは書かない。
- **流れ**：市場に着く → 張姐（必須）→ 仕込む量を選んで出汁を買う → 買い物（海叔・ミンは寄った人だけ）→ 市場を出るときに梁伯（必須）。
- 火事の翌日。昨夜「分からない」だった物が、今朝は「現物」と「段取り」になっている。ただし、元に戻ったわけではない。人の手と、借りた箱と、遠回りで続いている。
- 雨は降っていない。港側の規制は続いている。
- **話し方**
  - 張姐：早口でたたみかける。最後は質問で締める。店主を「アンタ」と呼ぶ。
  - 梁伯：命令と説教。同じことを二度言う。「〜しな」「〜とる」。答えを急がない。
  - 海叔：愛想がいい。「〜だよ」「〜ね」。娘の話が混ざる。
  - ミン：ぶっきらぼうな職人。話が飯に寄る。
  - 店主：短く受ける。
- **この場面で伝えること**
  - 張姐：骨は別の口から着いた。頼んでくる名前は「曜海聯運」で、火事の前にも来ていた名前（必ず通る）。
  - 梁伯：道が通れないことと、水が出ないことは別。計器には、誰が頼んだ仕事かまでは出ない（必ず通る）。

## 張記肉類加工　張姐　※市場に着いたとき

張姐「来たね。あるよ、骨。今日は袋より先に、中を見ていきな」  
店主「着いたか」  
張姐「着いた。昨夜は言えなかった『着いた』を、今朝やっと言えたの。もう冷やしてある」  
店主「車は入れたのか」  
張姐「大きいのは別の口まで。そこから小分けにして、何回も。運転手が降ろして、うちの子も受け取りに出たのよ？」  
店主「いつもより人の手が要るな」  
張姐「要る。保冷箱も借りた。返す先は、この札。読める？」  
店主「字がでかい」  
張姐「でかく書いたの。返す段になって、箱の持ち主まで迷子にしたくないでしょ？」  
店主「こっちの札、裏にも同じ字があるぞ」  
張姐「積むと片方が隠れるから。表だけじゃ、また箱を下ろすことになるでしょ」  
店主「誰が書いた」  
張姐「うちの子。私よりでかく書いたから、今日はそのままにした」  
店主「運んだ分の金は」  
張姐「そっちは、まだ話してる最中。荷が着いたからって、話まで着いたわけじゃないのよ」  
店主「骨の勘定は、ここか」  
張姐「ここ。アンタに売る分の話は、今できる」  

店主「上の荷捌き場、もう動いてるってな」  
張姐「うちの運転手も、次はそっちへ着けろって。頼んでくる名前、昨日よりはっきり書いてあったよ」  
店主「曜海聯運か」  
張姐「そう。火事の前にも来てた名前。あのときの紙、捨てなくてよかったと思わない？」  
店主「前の窓口の紙もな」  
張姐「全部とっとく。口が替わったって、前の勘定まで替わるわけじゃないもの」  
張姐「……一晩で門が開くもんかね。うちなんか、棚ひとつ動かすのに三日かかるのに」  
店主「前から支度してたんだろ」  
張姐「でしょうね。誰の支度かは知らないよ。うちは骨屋。門のことは、門の人が答えればいいの」  
店主「お前も寝てない顔だぞ」  
張姐「寝たよ。椅子でね。起きたら腕の跡が額に付いてた」  
店主「今は消えたな」  
張姐「箱を開けてたらね。……アンタも、そんなに覗かなくていいよ。ちゃんとあるから」  
店主「今日も鍋は出せるか」  
張姐「出せる分は、今ここにある。あとはアンタが炊くの。昨日までと同じように」  
店主「同じように、ね」  
張姐「道が替わっても、骨を煮る時間は縮まらないでしょ。で、今日はどれ位仕込む？」  

〔ゲーム〕仕込む量を選び、出汁を購入。買える量はいつもどおり（火事のせいで減らさない）。

張姐「袋の口、こっち向き。……うん。その持ち方なら大丈夫」  
店主「今日はすぐ帰って冷やす」  
張姐「分かってるならよし。アンタ、ゆうべ寝てないでしょ。夜、ちゃんと売っておいで。それから寝るのよ？」  

## 海隆鮮貨　海叔　※寄った人だけ（店ごとの会話の仕組みができたら）

海叔「こっち、見ていいよ。今朝届いて、もう確かめた方だからね」  
店主「箱が違うな」  
海叔「借り物だよ。名前の札は濡らさないでね。返すとき困るから」  
店主「借りた箱で、ここまで来たのか」  
海叔「決まるまで、積まないで待ってもらったんだ。それから動かして、ここで受け取った。先に出てたら、どこかの道で待たせてたね」  
店主「冷えて着いたか」  
海叔「記録を見て、中も見た。今夜使う分は勧められるよ。次の便は、まだ同じ約束ができないけど」  
店主「今日は、そこまで分かればいい」  
海叔「うん。昨夜より、返事が一つ増えた。一つだけどね」  
店主「今日は早じまいか。札、もう出してるぞ」  
海叔「娘と飯の日でね。片づけを代わってくれる人が、今朝やっと決まったんだ」  
店主「この忙しい日にか」  
海叔「全部落ち着いたら、って言うと、また日が決まらないからね。朝、起きてるかって連絡が来たんだ」  
店主「返したか」  
海叔「顔の写真を送ったら、『寝て』って。魚の写真より効いたよ」  
店主「魚は今日も送るのか」  
海叔「今夜は持っていく。食べる方の感想も、たまには聞きたいからね」  
店主「売り物の説明を始めるなよ」  
海叔「それも言われた。今日は、おいしかったか先に聞かないでって」  
店主「普段は聞くのか」  
海叔「ひと口で。今夜は、娘が食べ終わるまで待つよ」  
店主「待つ用事が増えたな」  
海叔「これは、席に座って待てるからね」  

## 福生豆腐麺房　ミン　※寄った人だけ（店ごとの会話の仕組みができたら）

ミン「袋、こっちへ寄せてくれ。そこは人が通る」  
店主「今日は店の中まで道案内か」  
ミン「機械は替わってない。人がいつもと逆から来るようになっただけだ」  
店主「手前の台も動かしたか」  
ミン「一つな。動かすと、今度は俺が回る方が長くなる」  
店主「どっちを取った」  
ミン「客が袋を落とさない方。拾って片づけるのは俺だ」  
店主「結局、自分のためか」  
ミン「お互いだろ」  
店主「包み紙、前の場所を探してるぞ」  
ミン「腕が先に伸びるんだよ。さっきも、何もない所で指をこすってた」  
店主「手も道を覚え直すか」  
ミン「そこに紙を戻せば、今日の俺は楽だ。明日の客がまた引っかかる」  
店主「戻さんか」  
ミン「今日はこのまま使う。明日の俺に慣れてもらう」  
店主「麺は、いつもの束か」  
ミン「ああ。持ち帰りに使うなら分けて包む。店で食わせるなら、こっちでいい」  
店主「今日は座って食っていく奴もいそうだ」  
ミン「じゃ、こっちだ。包みを増やすと、お前が開ける回数も増える」  
店主「よく分かるな」  
ミン「毎朝やってる。……昨日、飯は食えたか」  
店主「片づけてからな」  
ミン「冷めてたろ。今日は、片づける前に自分の分を取っとけ」  
店主「お前は」  
ミン「食った。朝いちばんにな。腹が減ってからだと、客の麺まで多めに茹でちまう」  
店主「何を食った」  
ミン「端の揃わない麺。自分の分を、最初から別にした」  
店主「売れない方か」  
ミン「長さが違うだけだ。俺の腹は文句を言わん」  
店主「味は」  
ミン「言ったら、俺が直すよ」  

## 共同水場　梁伯　※市場を出るとき

梁伯「そこへ下ろしな。そこだ。今朝、こっちを空けた」  
店主「水は出るんだな」  
梁伯「出とる。ほら、あんたの水缶でも、いつもの所まで来る」  
店主「夜中の連絡、助かった」  
梁伯「出るのか出んのか、聞く者が多かったからな。道が通れんことと、水が出んことは別だよ。別だ」  
店主「昨日の道は使えなかった」  
梁伯「だから置く場所もこっちへ替えた。逆から来た者が、缶を抱えたまま回らんで済む」  
店主「白い線、また引いたか」  
梁伯「前のは消した。二本とも残すと、好きな方へ置くからな」  
店主「俺も置きそうだ」  
梁伯「知っとる」  
店主「みんな、前の線を探すか」  
梁伯「線を探す者はまだいい。顔を上げずに、いつもの所へ置くんだ」  
店主「身体が覚えた方か」  
梁伯「そうだ。だから先に、こっちで声をかけとる」  
店主「喉が先に疲れるな」  
梁伯「水はある。飲んでから、また言うよ」  

店主「旧倉庫側の蛇口は、見に行けたか」  
梁伯「行けん。見るのは次だと言ったら、その次が無くなった。規制の外から数字を見ても、現物を見たことにはならんよ」  
店主「水が増えた頃には、もう仕事が移ってたんだな」  
梁伯「夜に使う者が増えたのは見た。誰が頼んだ仕事かまでは、ここの計器には出んよ」  
店主「数字だけじゃ、全部は分からんか」  
梁伯「分かることを見とるんだ。分からんことは、分からんまま帳面に残す。……今は、あんたの水が溢れそうだよ」  
店主「止めた」  
梁伯「蓋をしてから持ち上げな。蓋だ」  
店主「……したよ」  
梁伯「よし。帰りは外側を回りな。港の門へ抜けようとするんじゃない」  
店主「また明日もか」  
梁伯「明日は、明日の札を見る。水缶は今日も明日も、蓋を閉める」  

〔ゲーム〕払うのは、いつもの日の分だけ。

## 実装メモ

| 項目 | 内容 |
|---|---|
| 張姐 | 7日目の市場の場面。「で、今日はどれ位仕込む？」は仕込む量を選ぶ場面の文。選んだあとに3行ある。買える量・値段は変えない。 |
| 梁伯 | 市場を出るときの場面。払い方と額は変えない。 |
| 海叔・ミン | 店ごとの会話の仕組みはまだ無い。必ず伝える情報は入れていない。 |
| 6日目からの返事 | 骨＝別の口から小分けで着いた（箱は借り物、運び賃の話はまだ）。魚＝受け取って、記録と中身を確かめた（次の便は約束できない）。水＝出ている。置き場を替えた（港側の道は通れないまま）。 |
| うまくやっていく感じ | 張姐の「でかく書いたの」、海叔の「返事が一つ増えた。一つだけどね」、ミンの「人がいつもと逆から来るようになっただけだ」、梁伯の「前のは消した。二本とも残すと、好きな方へ置くからな」。みんな、自分の持ち場の小さな直しで続けている。 |
| 謎が残る所 | 張姐「一晩で門が開くもんかね」「誰の支度かは知らないよ」。梁伯「見るのは次だと言ったら、その次が無くなった」「誰が頼んだ仕事かまでは、ここの計器には出んよ」「分からんことは、分からんまま帳面に残す」。旧倉庫側の蛇口は、6日目の「自分で見るのは次だ」のまま、この週には自分で確かめられず終わる。蛇口が破壊された、今後も確認できない、とまでは決めない。 |
| 暮らしの部分 | 海叔の娘との飯（6日目「先に日を決めようと思ってる」の続き）、ミンの「片づける前に自分の分を取っとけ」。 |
| 今回の加筆 | 箱の裏にも書いた返却先、張姐の椅子での仮眠、海叔が娘の感想を待つ食卓、ミンの手が覚えた売り場と自分の麺、梁伯の声かけ。到着した荷の裏にある手間を足した。 |
| たたき台から変えた所 | 張姐に「一晩で門が開くもんかね」からの3行と、最後の「それから寝るのよ？」を足した。梁伯に「見るのは次だと言ったら、その次が無くなった」「分からんまま帳面に残す」を足し、同じことを二度言う癖を付けた。「夜中の返事」→「夜中の連絡」（梁伯のDMは返事ではなく、向こうから来た連絡なので）。 |
