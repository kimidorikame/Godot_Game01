# 『夜湯』7日目・宵の口　リン（新人警官）

## この稿について

- **表記の決まり**：`〔ゲーム〕` の行はゲームの処理（表示しない）。「名前「セリフ」」だけを会話枠に出す。ト書きは書かない。
- **話し方**
  - リン：丁寧で生真面目。冗談を真に受けてから、少し遅れて返す。「〜です」「〜ました」。一人称は「私」。
  - 店主：短く受ける。
- 休憩中。4回目の来店。1杯。注文は 酸っぱい＋歯ごたえ。好物は米麺。
- 話すのは、公表された範囲だけ。捜査の中のことも、自分の疑いも、屋台では口にしない。
- 屋台の会話には、裏の立場をにおわせる文を入れない（裏はタイムラインの暗号だけ）。
- 2日目に入口を探していた新人が、7日目には店主に「明日使う道」を教えて帰る。

## 本編

### 来店・注文

リン「こんばんは。今日は、ここまで自分の地図だけで来られました」  
店主「通れる道が減ったのにな」  
リン「減った方も、書いてあります。前の線をそのまま辿らずに済みました」  
店主「休憩は取れたか」  
リン「はい。交代してから来ました」  
店主「酸っぱい汁と、噛める具だな」  
リン「お願いします。米の麺も、あったら」  
店主「もう覚えた」  
リン「……ありがとうございます。今日は一日、説明をする側だったので。説明しなくていいことがあると、助かります」  
店主「椅子の場所も同じだ」  
リン「そこは、見れば分かりました」  

### 提供と反応

〔ゲーム〕1杯。酸っぱい＋歯ごたえ。好物は米麺。判定の結果で、次のうち1つだけ出す。

- **GREAT**　リン「米の麺も。酸っぱくて、噛めるものもありますね。……はい。これが食べたかったです」
- **GOOD**　リン「この酸っぱさです。具もしっかり噛めます。今日は一口ずつ、ちゃんと分かります」
- **OK（酸っぱさは合った）**　リン「汁は好きです。具は、もう少し噛み応えのあるものがよかったです」
- **OK（歯ごたえは合った）**　リン「噛み応えはあります。酸っぱい汁で食べるつもりで、待っていました」
- **BAD**　リン「……酸っぱい汁と、噛み応えのある具をお願いしたんですが。今日は違う方ですね」

### 食事・調べている場所

店主「朝の発表、読んだ。配線の所を調べてるって」  
リン「はい。旧倉庫の仮設配線付近を調べている、と公表されています」  
店主「じゃあ、線から火が出たのか」  
リン「原因はまだ特定されていません。調べている場所と、原因が分かったことは別です」  
店主「放火って話は」  
リン「現時点で、放火を裏付ける証拠は確認されていない、という発表です」  
店主「事故に決まったわけでもないんだな」  
リン「はい。今、お伝えできるのはそこまでです」  
店主「いつ分かる」  
リン「分かりません。分かったときに、発表があります。……発表が無いまま終わることも、あります」  
店主「その先を、みんな聞くんだろ」  
リン「聞かれます。私も、分かっていないことを答えるわけにはいきません」  
店主「分からんって言うのも、疲れるな」  
リン「昨日と同じ答えでも、今日初めて聞く方がいますから」  

〔ゲーム〕6日目に夜勤警備員が屋台に来ていた場合だけ、次の5行を出す。来ていなければ、5行とも出さない。

リン「旧倉庫の夜番の方から、ここの店主に礼を、と言われました。昨夜、交代のときにスープを食べたそうですね」  
店主「会ったのか」  
リン「はい。規制の外で、ご本人と話しました。持ち場のことを確認していました」  
店主「……そうか。なら、また来いって伝えてくれ」  
リン「会えたら、伝えます」  

### 食事・戻れない人、上へ行く人

店主「上の荷捌き場は動いてるんだな」  
リン「人と車が入っています。入口の受付も、もう使われていました」  
店主「下の門は、閉まったままか」  
リン「構内全体が規制されています。旧倉庫だけでなく、作業を止めていた班の倉庫にも戻れません」  
店主「荷がある奴も困るな」  
リン「私物だけ取りたい、という方もいました。上着、工具、弁当箱。荷物ごとに、持ち主がいるんですね」  
店主「置いて帰った物が、急に取りに行けなくなるか」  
リン「はい。通せないと伝えて、問い合わせる先をご案内しています」  
店主「上へ行けと言えば済む話でもないな」  
リン「新しい仕事が決まった方と、まだ返事を待っている方がいます。行く場所を聞くと、答えが違います」  

店主「目の端の時計は」  
リン「消してあります。……今日は、消したことを忘れていました」  
店主「やっと、椀がよく見えるか」  
リン「はい。底が見え始めました」  
店主「急いで食うなよ」  
リン「急いでいません。味の方で進んでいます」  

### 食事・家の鍋

店主「家の椀は、しまってあるって言ってたな」  
リン「はい。その母から、写真が来ました。椀ではなく、鍋の写真でした」  
店主「そっちを覚えてたか」  
リン「柄のところが欠けていて。見たら、ああ、この鍋だ、と」  
店主「麺より先にか」  
リン「はい。『これでよければ、帰ったときに作る』と」  
店主「よかったな」  
リン「帰る日は、まだ決められません。でも、返事はしました。『それがいい』と」  
店主「こっちは、家までの間に食っとけ」  
リン「そうします。ここは、もう迷わず来られるので」  

### 会計・明日も使う道

〔ゲーム〕会計（1杯分）。

リン「明日の仕入れも、荷車ですか」  
店主「ああ。朝の荷がどこへ着くかにもよるが」  
リン「今の規制なら、市場の外側を回る方です。細い近道は使わないでください。入口の掲示も更新されています」  
店主「昼に梁伯にも言われた」  
リン「では、同じ案内を出せていますね。こちらは、さっき確認した分です」  
店主「送ってくれ。時刻も付けてな」  
リン「はい。通れる口が変わったら、分かった範囲でまた送ります」  
店主「今日は水缶を半分持てとは言わんぞ」  
リン「……はい。今日は、最初から冗談だと分かりました」  
店主「最初は入口を探してたのにな」  
リン「ここへ来る道を教わったので、ほかの道も覚えられました」  
店主「また腹が減ったら来い」  
リン「はい。ごちそうさまでした。巡回に戻ります」  

## 実装メモ

| 項目 | 内容 |
|---|---|
| 注文 | 酸っぱい＋歯ごたえ（データのまま）。好物は米麺。 |
| 分かること | 警察の発表は「仮設配線付近を調査中。現時点で放火を裏付ける証拠は確認されていない。原因の特定には至っていない」。ニュース1本目と同じ文言にそろえる。「事故だった」「放火ではなかった」に読み替えない。 |
| 謎が残る所 | 「調べている場所と、原因が分かったことは別です」「発表が無いまま終わることも、あります」。警官として正しい一般論で、裏をにおわせる文ではない。 |
| 表と裏 | 屋台では、入口を探していた新人が、店主に明日の道を教えて帰る。同じ晩の暗号（21:25）では「屋台との接触を維持。店主は道と土地の話に使える」。親切は本物で、同じ知識が別の相手にも渡っている。屋台の中では、それを一切見せない。 |
| 夜勤警備員の5行 | 6日目に警備員が来ていた場合だけ出す（6日目の火事の場面と同じ「モブが来た」印を使う）。印が無ければ、常に出さない。一人の無事が分かるだけで、「全員無事」「けが人なし」には広げない。 |
| うまくやっていく感じ | 「減った方も、書いてあります」「荷物ごとに、持ち主がいるんですね」「消したことを忘れていました」。家からの鍋の写真と「それがいい」。 |
| つながり | 「自分の地図だけで来られました」＝2日目に入口を探していた。「目の端の時計」＝2日目「時計だけが止まりません」、4日目「食事中だけ、消せます」。「家の椀はしまってある」＝4日目（母の返事）。「水缶を半分」＝5日目の冗談。「同じ案内を出せていますね」＝昼の梁伯。 |
| たたき台から変えた所 | (1) 家の鍋：4日目の加筆（母の返事「私の椀はしまってあるから」）を店主が持ち出し、その母から鍋の写真が来た、とつなげた。(2) 時計：4日目にもう「食事中だけ消せます」と言っているので、「消したことを忘れていました」に進めた。(3) 「いつ分かる」「発表が無いまま終わることも、あります」の2行と、水缶の冗談の2行を足した。 |
| 道を端末へ送る話 | 会話の上だけ。地図の画面や道を選ぶ仕組みは足さない。 |
| あとで足すもの | 具だくさんの一言、断ったときの一言。 |
