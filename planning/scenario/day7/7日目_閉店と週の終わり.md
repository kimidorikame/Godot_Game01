# 『夜湯』7日目　閉店と、この週の終わり

## この稿について

- **表記の決まり**：`〔ゲーム〕` の行はゲームの処理（表示しない）。「名前「セリフ」」だけを会話枠に出す。ト書きは書かない。音・光は〔ゲーム〕の行に書いてある（演出の指示）。
- ターニャ婆が帰ったあとに、かならず1回起きる。客の出来や売上で中身は変わらない。
- **出さないもの**：新しい客、意味ありげな人物、犯人からの連絡、次の事件の速報、8日目への呼び出し、犯人当ての答え、原因を言い切る語り、全員が集まるお祝いの場面。
- 謎は、ここより前に置いてある（朝の記事、ニカに届いた返事、リンの暗号、婆が見た高台の看板）。最後に置くのは、瓶の箱と、明日の支度。
- 店主の独り言は短く（6日目の共通場面と同じ扱い）。

## 1．閉店　※ターニャ婆が帰ったあと

〔ゲーム〕手押し車の音が遠ざかる。空になった瓶の箱を、屋台の下に戻す。棚・看板・雨よけなどの見た目は、プレイヤーが実際に買った状態のまま。買っていない物を出さない。

店主「……箱は、またここだな」  

〔ゲーム〕洗った椀を重ね、小さいお玉を道具の所へ戻す。売上と残りは、プレイヤーの結果のまま処理する。売り切れた・大儲けした、とは見せない。

〔ゲーム〕鍋の火を落とす。端末は、受け取った連絡の画面を閉じるだけ。新しい通知は鳴らさない。

店主「明日の道は、明日見るか」  

〔ゲーム〕屋台を、引ける形に畳む。

店主「よし。今日はここまで」  

## 2．朝の音と、タイトル

〔ゲーム〕朝の市場の音。店を開ける人の声、台車の音。港の方は静かなまま（規制が続いている）。坂の上から、別の車が下りてくる音。街が元に戻ったのではなく、違う道で続いていると分かる音にする。

〔ゲーム〕空の瓶の箱に、洗いかごの影が落ちる短い絵。暗転。「夜湯」のタイトル。そのあと、今ある7日目の結果の画面へ進む。

## 実装メモ

| 項目 | 内容 |
|---|---|
| 場面の位置 | ターニャ婆の退店のあと、結果の画面の前。6日目に作る「閉店の前の短い場面」の形を使う。 |
| 店主の3行 | 「……箱は、またここだな」（瓶を渡して、また溜める箱）。「明日の道は、明日見るか」（梁伯「明日は、明日の札を見る」、レックス「明日のことは、明日聞く」と同じ調子。足した1行）。「よし。今日はここまで」。 |
| 終わり方 | 分かったこと：火事の前から、仕事の窓口と下請けが移り始めていた。ニカは言い切りを撤回した。常連との小さな約束（瓶、道、自転車）は果たされた。／分からないまま：出火の原因、得をした側がどこまで関わったか、リンの報告先、ニカに届いた返事の中身、兄貴分の電話の中身。 |
| 結果の画面 | 今ある画面をそのまま使う。事件のまとめの文を出しているなら、「原因は特定されていない」にそろえる（「事故」「放火」と言い切らない）。 |
| 絵と音 | 瓶の箱の絵、朝の市場の音、坂の上から下りてくる車の音。絵が無ければ、音と暗転だけで通じる。 |
| たたき台から変えた所 | 店主の独り言に「明日の道は、明日見るか」を足した。「お玉」を「小さいお玉」にした。ほかは、たたき台のまま。 |
