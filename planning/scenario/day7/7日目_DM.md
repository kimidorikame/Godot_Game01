# 『夜湯』7日目　DM（朝の10通と、夜半のあとの2通）

## この稿について

- 朝のDMは、店主が休んでいる間に届いていて、次の準備で読む。通知で店主を起こす演出にしない。
- DMは受け取るだけ（店主の返事は画面に出さない）。それぞれの文だけで用が通じるように書いた。
- リン・ニカ・ターニャ婆は今夜来るので、このDMを来店予告の代わりにする（同じ人の予告の文と重ねない）。
- 阿強・セティヤ・レックスは今夜来ない。DMで、それぞれの「そのあと」を届ける。
- 遊びに効くことは本当のことだけ。金額・数字（時刻以外）は入れない。
- **話し方**：張姐は早口で、質問で締める。阿強は「〜じゃん」「〜なんだけど」「マジで」。セティヤは「〜わ」「〜のよ」。ターニャ婆は音声（文字起こし）。リンは丁寧。ニカは短く跳ぶ。レックスはぶっきらぼう。港湾労働者はむきになる若手。

## 実装メモ

| 項目 | 内容 |
|---|---|
| 置き場所 | data/dm/week7.json の7日目。今の仮のDMは外す。 |
| 阿強の4通 | 写真つきの1通目はかならず届く。3通目は、1日目に3杯目（門の人の分）を出したかどうかで文が替わる（今ある「条件で替わる文」の形。2日目の阿強のDMと同じ印）。門の人がいなかった、というだけで、亡くなった・行方不明、とは見せない。自転車の代金を店主の所持金から引かない。 |
| 阿強の「そのあと」 | 4日目「そいつで最初に何を運ぶ？」「最初くらい、空で走るって」→「初乗り、結局仕事だった」「でも下りは空だった。そこだけは、ちゃんと俺のだった」。たたき台では店主が返信で突っ込んでいたが、DMは受け取るだけなので、阿強が自分で言う形にした。 |
| レックス | **足した1通。** レックスは7日目に来ない。6日目の「俺には、まだ何も来てねえ」に、「俺にも来た」が返る。行くとも行かないとも決めず、腕の点検を理由に一日延ばす。「兄貴には、まだ何も聞いてねえ」＝6日目の「聞いて、答えが返ってきたら、どうすんだ」の続き。タイムライン 20:00 の「継ぎ目」（腕の点検）とつながる。フル版へ残す所。 |
| セティヤ | 6日目の「帰りに使うつもりだった裏の道、今は出ないでって言われた」「今夜の『あとでね』、まだ使えそうにないわ」の続き。本人が帰れたことだけを伝える。店が元どおり、とは言わない。 |
| ターニャ婆 | 音声で送る人。本文は音声の文字起こしとして出す（見た目は今のDMのまま）。 |
| 夜半のあとの2通 | ニカの退店で、店主が「俺に送ってきた奴にも、知らせとく」と言う。その返事。店主の文は出さない。差出人は「港湾労働者」（6日目に投稿を転送してきた人。1日目の労働者B）。営業中に届くDMの形（6日目に作るもの）を使う。難しければ、ニカの退店の直後に画面へ出す。 |
| 卵 | 5日目「卵を割らずに仕事場へ持っていく」、6日目「卵、買っといてよかった」→ 7日目「卵は帰りに買う。帰りがあるって分かったからな」。 |
| たたき台から変えた所 | 阿強と店主のやり取りを、阿強だけの4通にした。「兄さん」→「門のおっさん」（1・3日目の呼び方）。張姐に「で、アンタ、少しは寝たの？」、セティヤに「あとでね」を足した。レックスの1通と、港湾労働者の2通（たたき台ではニカの場面の終わりにあった）を、DMとして足した。 |
