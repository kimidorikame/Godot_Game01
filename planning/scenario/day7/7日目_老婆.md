# 『夜湯』7日目・明け方　ターニャ婆（老婆）／この週の最後の客

## この稿について

- **表記の決まり**：`〔ゲーム〕` の行はゲームの処理（表示しない）。「名前「セリフ」」だけを会話枠に出す。ト書きは書かない。
- **話し方**
  - ターニャ婆：「〜だよ」「〜かい」「〜おくれ」「〜しな」。物の話は細かい。見たことと、見ていないことを分けて話す。一人称は「あたし」。
  - 店主：短く受ける（婆の「〜かい」は使わない）。
- 3回目の来店。いつもと反対側から来る。新しい荷捌き場に合わせて、回る順番を替えた。
- 1杯。注文は うましお＋腹もち。好物はモツ。
- 1日目から取り置いていた瓶を、今夜渡す。瓶の受け渡しは、料理の出来に関係なく進む。お金のやり取りは足さない（会話の上だけ）。
- **この週の最後の客。** 婆が帰ったあとに、新しい客も、意味ありげな人物も出さない。

## 本編

### 来店・違う方から来た音

〔ゲーム〕いつもとは反対の方から、手押し車の音。店主が音の方を見る短い間。不穏な音にはしない。

店主「そっちから来たのか」  
ターニャ婆「聞こえたかい。今日は荷がよく鳴るからね」  
店主「鍋の蓋じゃないな」  
ターニャ婆「瓶だよ。上で少し出た。缶と同じ籠には入れないようにしたけどね」  
店主「高台を回ったか」  
ターニャ婆「先にね。空の荷台で上って、拾ってから下りる方が楽だった」  
店主「前に考えてた順番か」  
ターニャ婆「一度回らないと分からないさ。近い道が、押しやすい道とは限らないからね」  
店主「今日は分かったか」  
ターニャ婆「下りで急ぐと、瓶が鳴る。そこは分かった」  
店主「割ってないだろうな」  
ターニャ婆「鳴ったら止まって、布を入れたよ。割れてからじゃ、布は役に立たないからね」  

### 注文

ターニャ婆「一杯おくれ。魚醤と、干した根っこの匂いのする、いつもの」  
店主「具は腹にたまる方だな」  
ターニャ婆「ああ。今朝も、もうひと回りする。モツがあれば、そっちも頼むよ」  
店主「回る所が替わっても、注文は替わらんな」  
ターニャ婆「あたしの腹まで引っ越したわけじゃないもの」  
店主「先に瓶を移すか」  
ターニャ婆「飯を先におくれ。瓶は逃げないよ」  

### 提供と反応

〔ゲーム〕1杯。うましお＋腹もち。好物はモツ。判定の結果で、次のうち1つだけ出す。

- **GREAT**　ターニャ婆「モツもあるね。いい匂いだ。……覚えててくれたかい。ゆっくり噛むよ、これは」
- **GOOD**　ターニャ婆「そう、このたれだよ。腹にもたまる。坂を下りてきた分、ちょうど腹が空いたところさ」
- **OK（うましおは合った）**　ターニャ婆「汁はいいね。具はもう少し、腹に残るのが欲しかったよ」
- **OK（腹もちは合った）**　ターニャ婆「腹は満ちそうだね。あの魚醤の匂いがあれば、もっとよかった」
- **BAD**　ターニャ婆「おや、今日は違う方が来たね。魚醤のきいた、腹にたまるのを頼んだつもりだったよ」

### 食事・新しい回収先

店主「上は何が出た」  
ターニャ婆「紙と缶。箱を空ける人はいるけど、置き場を決める人がまだ忙しそうだった」  
店主「勝手に取るなと言われたか」  
ターニャ婆「だから聞いたよ。持ってっていいのか、まだ使うのか。新しい所では、まずそれさ」  
店主「返事は」  
ターニャ婆「乾いた方は使うって。あたしが持ってきたのは、もう要らない方」  
店主「拾える量は増えたか」  
ターニャ婆「今日は少しね。だが、毎朝出るかまでは分からない。前の所が回れなくなった分もあるし」  
店主「全部、上で済めば楽だな」  
ターニャ婆「そうでもないよ。買ってくれる油屋は下だ。缶を持ってく所も変わってない」  
店主「拾う場所だけ替わるか」  
ターニャ婆「だから順番を替えたんだよ。拾ったまま抱えてたら、お金にはならないもの」  

店主「上の灯りの下、今日は人がいたか」  
ターニャ婆「いたよ。この前は誰も立ってなかった所に、今朝は列ができてた」  
店主「看板は見たか」  
ターニャ婆「今度は見た。字は読めたよ。だが、あれが誰の名前なのかは、読んでも分からなかったね」  
店主「聞かなかったのか」  
ターニャ婆「紙と缶をもらいに行って、門の持ち主まで聞くもんじゃないさ。聞いて答える人も、いなさそうだった」  

店主「元の門は見たか」  
ターニャ婆「遠くからね。中へは行かないよ。あそこにある物は、持ち主の返事も聞けない」  
店主「燃えたからって、拾っていい物にはならんな」  
ターニャ婆「そうさ。まだ誰かが、取りに戻りたい物かもしれないだろ」  

### 食事・若いのの車体

店主「阿強から、写真が来た」  
ターニャ婆「あたしにも来たよ。今度は売り物の写真じゃなかった。部屋の床に立ててあったよ」  
店主「買ったってな」  
ターニャ婆「よかったねえ。『これ、売れる？』じゃなくて、『これ買った』だったよ」  
店主「初乗りは仕事だったそうだ」  
ターニャ婆「あの子らしいね。鍵の輪っかも見せてきた。番号の札が付いてないってさ」  
店主「そこを喜んでたか」  
ターニャ婆「毎日、自分で触る物だもの。あたしはこの持ち手を替えたとき、しばらく握って確かめたよ」  
店主「今のか」  
ターニャ婆「ああ。布を巻き直して、手に合うようにした。新しい物じゃなくても、自分の物にはなるさ」  

店主「脚の端子は、まだ直すつもりらしいな」  
ターニャ婆「そっちの金は取っとけと、あたしも言った。走りたいなら、走れる脚にしとかなきゃね」  
店主「言われてばかりだな、あいつ」  
ターニャ婆「欲しい物の写真を送る相手を、間違えたんだよ」  

### 食事・今夜の屋台

ターニャ婆「骨は来たんだね」  
店主「別の口からな。箱も借りて運んだらしい」  
ターニャ婆「誰かが運んだ分、あたしがここへ座れたわけだ」  
店主「朝まで、来る時刻も分からなかった」  
ターニャ婆「あたしも、今夜どっちから来るか決めてなかったよ」  
店主「いつもの通りじゃないことばかりだ」  
ターニャ婆「でも、あんたの鍋の場所は分かった。坂を下りたら、明かりがあったからね」  
店主「消す前でよかったな」  
ターニャ婆「あたしも、そう思って座ったよ」  

### 会計・初日の瓶

〔ゲーム〕会計（1杯分）。いつもどおり払う。最終日だからといって、無料・値引き・お礼の金は足さない。

ターニャ婆「ごちそうさん。勘定は、これでいいかい」  
店主「いいよ。瓶、出すぞ」  

〔ゲーム〕洗って乾かしておいた瓶を、箱から出す。本数は言わない（プレイヤーの使った材料と食い違わないように）。

ターニャ婆「うん。口も欠けてない。よく乾いてる」  
店主「栓はしなくていい、乾かしとけって、言ったろ」  
ターニャ婆「覚えてたね」  
店主「何回も言われたからな」  
ターニャ婆「何回も来たからだよ」  

店主「油屋へ持ってくのか」  
ターニャ婆「そう。この形が欲しいって返事が来てる。詰め直して、小分けに売るんだと」  
店主「箱ごとでいいぞ」  
ターニャ婆「それは、あんたがまた溜める箱だろ。袋を持ってくと言ったじゃないか」  
ターニャ婆「口を上にして、こっち。……そう。そこはあたしが押さえるよ」  

〔ゲーム〕二人で瓶を袋へ移す。瓶が触れる音を一つ。荷台に布を入れる音。長い回想や、全員が集まる絵は挟まない。

店主「また空いたら、洗っとく」  
ターニャ婆「ああ。頼んだよ」  

### 退店

店主「このあとは下か」  
ターニャ婆「下だよ。今日は帰りに上らずに済む」  
店主「荷台、重くなったぞ」  
ターニャ婆「だから、先に上ってきたんだろ」  
店主「そうだった」  
ターニャ婆「じゃ、またね。あんたも畳む前に、小さいお玉をしまう所は見ときな」  
店主「袋の底へは入れないよ」  

〔ゲーム〕ターニャ婆が帰る。手押し車の音が、今度はいつもの下りの方へ遠ざかる。振り返らせない。このあと、閉店の場面へ進む。

## 実装メモ

| 項目 | 内容 |
|---|---|
| 注文 | うましお＋腹もち（データのまま）。好物はモツ（スタミナの具。腹もちの代わりにはならない）。GREAT は、薬膳ナンプラーだれ＋腹もちの具＋モツ。 |
| 瓶 | 1日目に取り置いた瓶を渡す。会話の上だけ（売り買い・臨時の収入・在庫の変化は足さない）。料理が BAD でも、断っても、瓶の受け渡しは起きる。 |
| うまくやっていく感じ | 回る順番を替えた（先に高台、拾ってから下りる）。「一度回らないと分からないさ」「あたしの腹まで引っ越したわけじゃないもの」「新しい物じゃなくても、自分の物にはなるさ」。拾う場所は替わっても、買ってくれる油屋は下のまま。 |
| 謎が残る所 | **足した6行。** 4日目に婆は「灯りだけが点いてる。誰も立ってない所を、あんなに明るくしてどうするんだか」と言った。7日目には、そこに列ができている。看板の字は読めたが、「あれが誰の名前なのかは、読んでも分からなかった」。聞いて答える人も、いなさそうだった。 |
| 元の門 | 「あそこにある物は、持ち主の返事も聞けない」。燃えた物を拾わない。婆の商売の筋であり、戻れない人がいることの言い方でもある。 |
| 最後の客 | 婆のあとに客を出さない。組の数が多い晩でも、モブは婆の前まで。 |
| つながり | 瓶「洗って乾かしときな。栓はしなくていい」＝1日目。「溜まったら取りに来る」＝4日目。小さいお玉＝1日目・4日目。阿強の「これ、売れる？」＝4日目のブレーキの写真。「部屋の床」＝4日目の「置けるか先に見たの」（床の荷物を片づけた）。高台の灯り＝4日目。 |
| たたき台から変えた所 | 高台の看板の6行を足した。「仕事場が替わっても」→「回る所が替わっても」（婆の仕事場は街ぜんぶなので）。最後の「お玉」を「小さいお玉」「袋の底」にして、1日目・4日目の言い方に合わせた。ほかは、ほぼたたき台のまま。 |
| あとで足すもの | 具だくさんの一言、断ったときの一言。 |
