# 情報量の実験（仕入れのとき、明日のタグをどれだけ知っていれば 1500 に届くか）

> 数字と事実の報告です。**数値の調整は提案しません**。目的は、最終版で客の好み（HOT・POWER などのタグ）を画面に出さず台詞やDMだけで伝えるときの、
> 「台詞で渡す情報の量」の目安を測ることです。生成：`node summarize_info_levels.mjs tables`（表の部分）。結果：`playthrough_results_info_levels.json`。

## 条件

- 方針は **基本GOOD（forecast_good）** と **初回から好物（favorite_oracle）** の2つ、各30シード、運営費75・`reach_true`。ゲーム本体は変えず、試遊のハーネスだけ（`playthroughs.gd` の引数 `info=levels`）。
- 土台は**補う版**（visible_improvise＝v3。注文のタグの素材が手元に無いとき、足りない軸〔味・具〕をほかの在庫で補う）。仕込みの大きさの見込み杯数もv3の値（前日の注文杯数・客足の言葉・DMの匂わせ）のまま。
- 変えるのは**仕入れの必要数**だけ。旧予報（上限案）のタグ別の必要数の1単位ごと（タグ×番号。常連の分とモブの分）に、確率 p で「前もって知っている」とする。
  知っている単位はそのまま数え、知らない分は v3 と同じ見積り（前の晩までに受けた注文のタグの割合）の同じ割合で置き換える：
  `必要数[タグ] ＝ 知っている単位の数 ＋ ceil(v3の見積り[タグ] × 知らない単位の数 ÷ 旧予報の必要数[タグ])`。旧予報の必要数が0のタグは、知らない割合だけ見積りを残す。
- 「知っているか」の当たりは、専用の決まった値（シード・日・グループ・タグ・番号のハッシュ）で、ゲーム本体の乱数（`seed()`）には触れない。同じ周・同じ日なら p を上げるほど「知っている」が増える一方になる。
- 組み合わせ：p＝0・25・50・75・100%（常連もモブも同じ割合）／常連だけ100%・モブ0%／モブだけ100%・常連0%。確認用に、p＝100% で見込み杯数も予報の値にしたもの。
- 「仕入れ費用」は日次の支出の `market`（市場での購入）の1周の合計。「出せなかった杯」は1周あたりの杯数で、素材（素材が足りない）・鍋（鍋が足りない）・断った・来られなかった（閉店のあと）の内訳（`PLAYTHROUGH_RESULTS_V3.md` と同じ分け方）。
- 1週間の杯数の内訳（組み立てから数えた概算）：常連（名前あり客）23杯、モブ約62人。必要数の単位（タグ×杯数）の約7割はモブの分。

## 要約

- **p を上げるほど、平均最終現金も 1500 達成率も上がる**（単調）。基本GOOD：平均 1316 → 1367 → 1436 → 1523 → 1665（p＝0→100%）、1500達成 0% → 3.3% → 20% → 66.7% → 100%。
  oracle：平均 1184 → 1251 → 1319 → 1428 → 1519、1500達成 0% → 3.3% → 6.7% → 23.3% → 66.7%。
  基本GOODの平均が 1500 を超えるのは p＝75%（1523）から。1500達成が 85% を超えるのは p＝100% です。
- GOOD以上率も同じ向きに上がる（基本GOOD：64.9% → 70.1% → 76.8% → 86.1% → 98.1%）。仕入れ費用も増える（基本GOOD：934 → 1103。知っているほど必要な量を買う）。
  出せなかった杯数は、どの条件でも1周あたり 0.3〜1.9杯で、差は小さい（内訳は素材と鍋がほとんどで、断ったは 0.1 以下）。
- **常連だけ／モブだけ**：モブの情報のほうが効く。
  - 基本GOOD：常連だけ100% → 平均 1371（p＝0 から＋55）、GOOD以上率 70.6%。モブだけ100% → 平均 1479（＋163）、GOOD以上率 94.7%。
  - oracle：常連だけ → 1333（＋149）、GOOD以上率 77.5%。モブだけ → 1370（＋186）、GOOD以上率 94.7%。
  - p＝100% との差に対する割合（基本GOODの平均）：常連だけ 約16%、モブだけ 約47%。GOOD以上率は、モブだけで p＝0 から p＝100% への上がり幅の約90%、常連だけで約17%。
  - 事実として、モブは1週間の杯数が常連の約2.7倍で、必要数の単位の約7割を占めます（上の条件）。1単位あたりの効きは、同じ程度です（基本GOODの平均で、常連 約1.2・モブ 約1.3 〔現金／単位／週〕）。
- **確認**：p＝0% は補う版（v3）と全周一致（基本GOOD・oracleとも 30/30周）。p＝100% は v2 に近い値（基本GOOD 1665 対 v2 の 1636、oracle 1519 対 1503）。
  p＝100% で見込み杯数も予報にしたもの（1672／1561）とも近く、仕込みの大きさの見込みの差は小さい。p＝100% が v2 よりわずかに高いのは、補う版の補い（欠けた軸をほかの在庫で補う）が加わるためとみられます（確かめてはいません）。

## 注意

- 知っている単位の当たりは、1単位ごとに独立（専用のハッシュ）です。実際の台詞は「ある客のタグを丸ごと伝える」形になり、単位ごとの独立とは違います（このため、ここでの p は「台詞で渡す情報の量」の目安です）。
- 原因は断定しません（事実の並べ方です）。各30シードで、1シード＝3.3ポイントです。数値の調整は、この報告では行っていません。
